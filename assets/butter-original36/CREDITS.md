# 버터 v36 — 원작 그림과 모션 우선

2026-11-03 사용자는 v35 조각 합성 결과를 거절하고, 고정 시안 대신 **원작 그림·모션
우선**을 선택했다. 한 시점 자료이며 네 방향 원본이 모두 있지는 않다는 한계도 안내했다.
v28/v32 승인 PNG와 v35 파일은 삭제하지 않고 보관하지만 현재 게임에서는 사용하지 않는다.

## 원본과 권리

- 사용자가 지정한 공개 뷰어: <https://viewer.dclnslde.com/>
- 선택: 버터 → 인게임 → 기본 / Normal (`battle/butter`, `Butter`).
- 원작 버터/트릭컬 이미지의 권리는 원 권리자에게 있다. 비공식 팬 프로토타입이다.
- 공개 접근 또는 비상업 제작이 재배포 허락을 뜻하지 않는다. 별도 재배포 라이선스는
  확인되지 않았으며 CC0/MIT 또는 상업 이용 가능 자료라고 표시하지 않는다.
- `Butter.png`: SHA-256 `3f0b809ecab4f6560e7a7d035b2e4fbb27d8493a2ff3a8bd4eb9c588de080613`
- `Butter.atlas`: SHA-256 `4e9610a78c7934cd9a7c608cdc9192edba5f19aac2ae9317a015eda0fd2b2b4a`
- `Butter.skel`: SHA-256 `191c9632527f68ffa821d0376e0e786d098097ad74740c7d5f7d568346682e09`
- 원본 URL은 모두 `https://viewer.dclnslde.com/spine/battle/butter/` 아래다.

## 포함된 프레임

| 파일 | 출처 | 프레임 |
| --- | --- | ---: |
| idle.webp | Idle | 120 |
| walk.webp | Move | 24 |
| shoot.webp | Attack1_1 | 36 |
| low.webp | Skill1_1 | 48 |
| high.webp | Ultimate1_1 | 72 |
| walkShoot.webp | 원본 리그에서 Move 하체 + Attack1_1 상체 결합 | 24 × 24 |

`poster.png`는 Idle 첫 프레임이다. `atlas.json/js`에는 각 셀, 클립별 공통 원점,
발사 마커, 이동 사격의 하체 검증 좌표를 저장한다. 모든 클립은 같은 소스 배율(.18)을
사용하고 개별 프레임의 크기/원점을 자동 보정하지 않는다.

원작 리그의 얼굴·머리·팔·다리·의상·손·꼬리·스킬 소품을 함께 렌더했다.
v35의 다른 그림 손 조각, 코드로 그린 팔, 별도 생성 보완 그림은 사용하지 않는다.
원작 바닥 그림자 두 슬롯만 숨긴다. 게임에서 그림자를 이미 그리기 때문이다.
색을 덧칠하거나 3D로 재생성하지 않았으며 WebP 품질 96으로 저장했다.

원본 스켈레톤·전체 텍스처·Spine/뷰어 런타임·음성은 게임에 포함하지 않는다.
원작을 렌더한 파생 이미지에는 여전히 원작 권리가 적용된다. 게임 실행 중 외부 뷰어에
요청하지 않으며 정적 WebP를 Canvas에 한 프레임씩 그린다.

## 이동 사격과 한계

- 원본에서 WalkShoot 클립을 찾은 것이 아니다. 같은 원본 리그에서 골반·다리·꼬리·
  가방/치마와 관련 IK/제약은 Move에서, 상체·손·줄·표정은 Attack1_1에서 가져왔다.
  이 상태를 리그의 월드 좌표/메시 계산 **전에** 적용해 전신 프레임으로 렌더한다.
- 하체는 같은 걸음 위상에서 사격 위상과 무관하게 동일해야 한다. `lowerChecks`로 검사한다.
- 이동 중 저학년 추가탄은 같은 이동 사격을 발사 시점에 맞춰 재시간화한다. 정지 저학년은
  원래 Skill1_1을 쓴다. 게임 공격 간격을 원작의 긴 클립 길이로 바꾸지는 않았다.
- 원작 Move의 공중 동작도 유지한다. 정지 그림의 다리를 늘려 접지로 위장하지 않는다.
- **한 시점의 3/4 원본**이다. 상하좌우 캐릭터 시점은 아직 없다. 좌우 반전하지 않으며
  게임의 바닥 화살표가 조준 방향을 표시한다. 캐릭터가 그 방향으로 돌아선다는 뜻은 아니다.
- 큰 스킬까지 전체가 보이도록 미리보기는 클립별 고정 카메라를 쓰지만 게임은 배율/바닥
  원점을 공통으로 쓴다. 기술 검사가 결합 동작의 미적 승인을 의미하지 않는다.

## 재현

Playwright + Chromium이 설치되고 지정 뷰어에 접근 가능한 환경에서:

```sh
node tools/bake-butter-original36.mjs
npm run check:butter-original
node tools/check-butter-original-browser.mjs http://127.0.0.1:4173
```

기존 설치 경로는 `PLAYWRIGHT_MODULE`, `CHROMIUM_EXECUTABLE`로 지정한다.
도구는 원본 3개 해시를 확인한다. 브라우저의 CA 문제는 같은 허용 URL을 시스템 CA의
curl로 전달하는 방식으로 처리하며 프록시/TLS 검증을 끄지 않는다.
