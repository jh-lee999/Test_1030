# 버터 전투 애니메이션 자료 및 프레임 구성

## 현재 데포르메 스프라이트와 보행

v25부터는 버터를 큰 머리·짧은 몸통·작은 발과 단순한 색면으로 표현한다. 긴 머리, 늘어진 귀, 노란 리본, 흰 소매·노란 옷·작은 분홍 하의, 새총 등 식별 특징을 남겼다.

- butter-chibi.webp는 7열 × 3행, 160px 칸의 완성된 전신 스프라이트 21장이다.
- 행은 정면/아래, 왼쪽 측면, 후면/위다. 오른쪽은 왼쪽 원본을 반전한다.
- 열은 정지, 왼발 접지, 통과, 오른발 접지, 반대 통과, 정지 사격, 고학년이다.
- 네 장의 보행 프레임을 이동 거리에 맞춰 재생한다. 이동 사격은 같은 보행을 유지하며 정지 사격 포즈로 바뀌지 않는다.
- 고학년도 같은 비율의 버터가 큰 새총을 든 프레임을 쓴다. 왕짱돌과 무적 효과는 게임 오브젝트로 표시한다.
- 관절 분할, 다리 길이 변경, 상체 메시 변형, 전신 프레임 크로스페이드를 사용하지 않는다. 전신 한 장을 그대로 그린다.
- 12px 이상의 투명 여백을 두고 발 기준선은 y=136으로 맞춘다.

원본은 tools/sprite-sources/butter-chibi-source.webp다. npm run pack:motion 또는 npm run pack:chibi로 전체 실루엣을 추출해 다시 배치한다. 원본이 균등 격자로 정확히 정렬됐다고 가정하지 않는다. npm run check:sprites는 실제 알파 픽셀과 여백, 발 기준선을 검사한다.

motion-preview.html에서 네 방향의 정지·걷기·정지 사격·이동 사격을 비교하고, sprite-preview.html에서 전신 21프레임을 확인한다. 기존 v23 관절/레이어 및 v24 메시 방식과 원본 에셋은 보관하지만 게임에서는 불러오지 않는다. 구형 레이어 재생성 도구는 npm run pack:legacy-motion이다.

## 확인한 공개 자료

- Triple3T/trickcaltool의 버터 기본 캐릭터 이미지
- 같은 자료의 저학년 스킬 아이콘 Icon_AdmissionSKill_Butter.png
- 같은 자료의 고학년 스킬 아이콘 Icon_GraduateSKill_Butter.png
- 한국어 데이터에 기록된 스킬 설명
  - 평타: 짱돌을 발사해 물리 피해
  - 저학년 버터 플라이!: 학년에 따라 피해와 타격 횟수가 증가하는 튕기는 탄환
  - 고학년 새쭁! 쓔튜라이크!: 거대한 짱돌로 범위 물리 피해

공개 자료는 외형·무기·동작 성격을 분석하는 참조로만 사용하고, 게임에 포함된 스프라이트는 별도로 제작했다.

## 보관 중인 구형 상세 시트

- butter-actions.webp: 오른쪽 측면 평타·저학년·고학년
- butter-actions-down.webp: 아래 방향 정면 평타·저학년·고학년
- butter-actions-up.webp: 위 방향 뒷모습 평타·저학년·고학년
- butter-walk.webp: 정면·왼쪽 측면·후면 6프레임 보행과 꼬리 좌우 움직임
- 공격 측면 시트는 오른쪽 원본을 왼쪽에서 반전하고, 보행 측면 행은 왼쪽 원본을 오른쪽에서 반전한다.

배포용 시트는 1920×960 크기의 6열 × 3행이며, 각 칸은 실제로 분리된 320×320 영역이다. 공격 시트 행은 평타, 저학년, 고학년 순서다. 모든 프레임에 최소 24px 투명 여백을 두고 발 기준선을 y=280에 맞춘다. 게임과 검사 페이지는 sprite-layout.js의 같은 좌표 및 렌더 함수를 사용한다.

생성 원본은 tools/sprite-sources에 보존한다. 원본은 행 높이가 서로 다르고 일부 효과가 옆 프레임에 걸쳐 있으므로 균등 6×3 좌표로 직접 읽으면 안 된다. npm run pack:sprites는 알파 연결 영역을 이용해 각 그림을 분리하고, 겹친 효과 경계를 지정해 다시 배치한다. 원본 하단에서 잘린 정면 고학년 4·5번 프레임은 같은 시트의 온전한 장전 프레임으로 대체하며, 발사 후 왕짱돌은 게임 투사체로 표시한다. 측면 저학년의 잘린 별 이펙트 프레임은 별도로 복원했다.

npm run check:sprites는 배포 이미지 72프레임의 실제 알파 픽셀, 투명 여백, 발 기준선, 크기를 검사한다. 두 도구는 Node.js와 ImageMagick을 사용한다. sprite-preview.html에서 게임과 같은 방식으로 모든 프레임을 확인할 수 있다.

후면 시트는 원본 복장 구조가 작은 게임 화면에서도 읽히도록 흰 반팔 셔츠 등판과 소매, 그 위의 노란 멜빵·허리띠·리본, 아래의 분홍 반바지와 줄무늬 양말을 서로 다른 색면으로 분리했다. 꼬리는 모든 프레임에서 허리 뒤 정중앙의 같은 뿌리에 연결한 뒤 옆으로 휘도록 하고, 다리 사이를 가리지 않게 했다. 머리와 꼬리는 공식 자료의 연한 회복숭아색 팔레트를 유지한다.

공격 판정은 별도 공격 타이머의 발사 시점에 생성된다. 현재 데포르메 보행 루프는 이 타이머와 독립적이므로 사격 때문에 걸음이 멈추지 않는다.
