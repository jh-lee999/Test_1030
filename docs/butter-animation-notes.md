**2026-11-03 실제 전투 모션 확인:** 사용자가 제공한 `viewer.dclnslde.com`의

공개 자료의 손 두 조각, 원화 기반 가림 영역 보완 후보, 정확한 출처/한계는

모션을 그대로 확보한 것이 아니라 승인 그림을 기반으로 각색한 동작 후보다.

## 보관: 과거 게임에 배포했던 Blender 모델과 리그 (v26)

`assets/models/butter.blend`는 평면 이미지를 휘는 파일이 아니라, 메시와 가중치·Armature·툰 재질을 가진 입체 모델이다. `tools/build_butter_model.py`로 생성한다. 크게 단순화한 머리와 짧은 발을 사용하되, 흰 반팔·노란 앞치마/멜빵·분홍 반바지·줄무늬 양말·긴 머리·귀 리본·등 중앙 꼬리·새총을 구분한다.

- 새총은 `slingshot.R` 뼈에 묶고 이를 `hand.R`에 연결한다. `hand.L`이 줄을 당기고 놓는다. 카메라 방향 때문에 손을 바꾸지 않는다.
- 두 끝점은 실제 포크 위치, 가운데는 왼손의 집는 위치를 따라가는 탄성 줄이다. 발사 때 손가락이 펴지고 줄이 포크 쪽으로 돌아온다.
- 보행은 반대 위상의 양발 접지·발 들기와 작은 골반 이동으로 구성한다. 머리·귀·머리카락·중앙 꼬리에 약한 후속 움직임이 있다.
- 네 방향은 같은 모델에 대한 직교 카메라 촬영이다. 오른쪽을 왼쪽의 반전으로 대체하지 않는다.
- 긴 머리가 팔을 가리지 않도록 좌우는 대칭인 3/4 시점으로 촬영한다. 같은 카메라 기준으로 새총 끝을 투영하므로 탄환 출발점도 함께 바뀐다.
- 평타/저학년은 보행 12단계 × 공격 8단계를 모두 렌더한다. 사격 타이머는 손, 이동 거리는 다리 프레임만 정한다. 이동 사격에서도 당기기·놓기가 생략되지 않는다.
- 고학년에는 손에 묶인 새총 뼈가 커지고 장전·발사한다. 왕짱돌은 기존 게임 투사체로 생성한다.
- 전체 500프레임을 128px 셀, 16열 × 32행의 `butter-model.webp`로 묶는다. 각 방향에 128칸을 할당하고 125칸을 사용한다.
- `butter-model.json`에 각 셀, 가동 단계, 월드 좌표의 양손과 포크 양끝을 저장한다. 모든 프레임에 최소 8px 투명 여백을 검사한다. 개별 프레임 크기를 바꾸거나 발 위치를 다시 정렬하지 않는다.
- 포크 양끝을 같은 카메라에 투영한 `butter-model-anchors.js`도 생성한다. 평타·저학년 탄환·왕짱돌과 발사 먼지는 이 좌표에서 생성되어, 몸 중앙이나 반대 손에서 나오지 않는다.

Blender 파일의 전체 타임라인은 Idle 1–25 / Walk 31–55 / Slingshot 61–85 / Walk_Slingshot 91–115 / High 121–145다. 기본 미리보기 구간 91–115에서 재생하면 이동 사격을 볼 수 있다. 리그·탄성 줄·가죽 주머니가 동일 타임라인에 묶여 있다. 개별 Action도 보존한다. Blender Text의 `START HERE - Butter model`에 사용법이 있다.

재생성은 `npm run render:animations` 후 `npm run pack:model`이다. `npm run check:sprites`는 실제 알파 여백·시트 좌표·카메라별 손 좌표 일치·이동 사격 중 팔 변화/발 유지도 검사한다. `tools/check-butter-model.py`는 Blender에서 실제 메시 가중치, 손-무기 연결, 네이티브 Action과 발/손 가동을 검사한다. `motion-preview.html`에서 동작, `sprite-preview.html`에서 프레임을 비교한다.

## 보관: v25 데포르메 스프라이트

v25부터는 버터를 큰 머리·짧은 몸통·작은 발과 단순한 색면으로 표현한다. 긴 머리, 늘어진 귀, 노란 리본, 흰 소매·노란 옷·작은 분홍 하의, 새총 등 식별 특징을 남겼다.

- butter-chibi.webp는 7열 × 3행, 160px 칸의 완성된 전신 스프라이트 21장이다.
- 행은 정면/아래, 왼쪽 측면, 후면/위다. 오른쪽은 왼쪽 원본을 반전한다.
- 열은 정지, 왼발 접지, 통과, 오른발 접지, 반대 통과, 정지 사격, 고학년이다.
- 네 장의 보행 프레임을 이동 거리에 맞춰 재생한다. 이동 사격은 같은 보행을 유지하며 정지 사격 포즈로 바뀌지 않는다.
- 고학년도 같은 비율의 버터가 큰 새총을 든 프레임을 쓴다. 왕짱돌과 무적 효과는 게임 오브젝트로 표시한다.
- 관절 분할, 다리 길이 변경, 상체 메시 변형, 전신 프레임 크로스페이드를 사용하지 않는다. 전신 한 장을 그대로 그린다.
- 12px 이상의 투명 여백을 두고 발 기준선은 y=136으로 맞춘다.

원본은 tools/sprite-sources/butter-chibi-source.webp다. npm run pack:chibi로 전체 실루엣을 추출해 다시 배치한다. 원본이 균등 격자로 정확히 정렬됐다고 가정하지 않는다. npm run check:sprites는 실제 알파 픽셀과 여백, 발 기준선을 검사한다.

기존 v23 관절/레이어, v24 2D 메시 변형, v25 21프레임 시트와 원본 에셋은 보관하지만 게임에서는 불러오지 않는다. 구형 레이어 재생성 도구는 npm run pack:legacy-motion이다.

## 보관 중인 구형 상세 시트

- butter-actions.webp: 오른쪽 측면 평타·저학년·고학년
- butter-actions-down.webp: 아래 방향 정면 평타·저학년·고학년
- butter-actions-up.webp: 위 방향 뒷모습 평타·저학년·고학년
- butter-walk.webp: 정면·왼쪽 측면·후면 6프레임 보행과 꼬리 좌우 움직임
- 공격 측면 시트는 오른쪽 원본을 왼쪽에서 반전하고, 보행 측면 행은 왼쪽 원본을 오른쪽에서 반전한다.

배포용 시트는 1920×960 크기의 6열 × 3행이며, 각 칸은 실제로 분리된 320×320 영역이다. 공격 시트 행은 평타, 저학년, 고학년 순서다. 모든 프레임에 최소 24px 투명 여백을 두고 발 기준선을 y=280에 맞춘다. 게임과 검사 페이지는 sprite-layout.js의 같은 좌표 및 렌더 함수를 사용한다.

생성 원본은 tools/sprite-sources에 보존한다. 원본은 행 높이가 서로 다르고 일부 효과가 옆 프레임에 걸쳐 있으므로 균등 6×3 좌표로 직접 읽으면 안 된다. npm run pack:sprites는 알파 연결 영역을 이용해 각 그림을 분리하고, 겹친 효과 경계를 지정해 다시 배치한다. 원본 하단에서 잘린 정면 고학년 4·5번 프레임은 같은 시트의 온전한 장전 프레임으로 대체하며, 발사 후 왕짱돌은 게임 투사체로 표시한다. 측면 저학년의 잘린 별 이펙트 프레임은 별도로 복원했다.

npm run check:sprites는 보관 이미지 72프레임의 실제 알파 픽셀, 투명 여백, 발 기준선, 크기도 검사한다. 두 도구는 Node.js와 ImageMagick을 사용한다.

후면 시트는 원본 복장 구조가 작은 게임 화면에서도 읽히도록 흰 반팔 셔츠 등판과 소매, 그 위의 노란 멜빵·허리띠·리본, 아래의 분홍 반바지와 줄무늬 양말을 서로 다른 색면으로 분리했다. 꼬리는 모든 프레임에서 허리 뒤 정중앙의 같은 뿌리에 연결한 뒤 옆으로 휘도록 하고, 다리 사이를 가리지 않게 했다. 머리와 꼬리는 공식 자료의 연한 회복숭아색 팔레트를 유지한다.

공격 판정은 별도 공격 타이머의 발사 시점에 생성된다. 현재 데포르메 보행 루프는 이 타이머와 독립적이므로 사격 때문에 걸음이 멈추지 않는다.
