# v75 — 아이템은 줍고, 증강은 층 보스 뒤에

2026-11-06 (Asia/Seoul). 사용자 요청대로 부서지는 상자를 나무상자로 바꾸고,
일반 아이템의3지선다를 없애 단일 자동 획득으로 변경했습니다.
전투/월드의 기존3층/끝방/동일 충돌 규칙은 유지하고 보상 흐름을 분리했습니다.

## 보상 흐름

- 첫 방·황금방·비밀방·도전 보상은 처음 생성할 때 아이템 하나만 추첨합니다.
  표시된 아이템의 바닥 중심38px 안으로 걸어가면 즉시 획득하며 F나 선택창은 없습니다.
  일시정지/메뉴 중에는 획득하지 않습니다. 주머니 I에서 효과를 다시 볼 수 있습니다.
- 같은 아이템을 상점 등에서 먼저 얻었거나12개를 모두 모았으면 해당 보상은4닢으로
  한 번만 지급합니다. 재방문/저장/획득 때 다시 추첨하지 않습니다.
- 상점은 자동 구매하지 않습니다. 실제 상품 하나하나를 가까이서 F로 구매하고
  기존 자금/재고/회복 상한과3/5닢 재입고 규칙을 유지합니다.
- 1·2층 보스를 처치하면 전투가 멈추고 증강3개가 자동으로 표시됩니다.
  고른 증강 하나는 이번 판 내내 유지됩니다. 이미 고른 증강은 다음 후보에 없습니다.
  선택 전에는 다음 층으로 갈 수 없으며, 선택 후 중앙 문에서 F로 이동합니다.
- 마지막 셰이디 뒤에는 더 싸울 층이 없으므로 추가 선택창 없이 탈출 문이 열립니다.
  일반 유물12종과 별도의 증강4종을 구분합니다. 보스 증강은 판당 최대2개입니다.

당시 권총/관통/도탄을 계승하며 child=true라 재귀 분열하지 않고100발 제한을 지킵니다.
왕짱돌의 여운은 살아 있는 왕짱돌마다0.32초 간격으로1초짜리 불씨를 남깁니다.
불씨는 반경38,0.4초당4피해이며 기존35개 구역 생성 제한을 공유합니다.
알뜰한 장난감은 획득 후 나무상자3개를 부술 때마다 폭탄 하나를 줍니다.
사격/폭탄 파괴 모두 세고, 바위/이미 부순 상자는 세지 않습니다.
반격의 틈은 피해 후 생존 시 반경140 적 탄환을 지우고 적을55px 밀칩니다.
밀치기는 동일 지형 충돌을 따르고2초 재사용 대기와 카운터도 저장/정지됩니다.
