# v64 · 버튼과 카드 피드백

- 일반 버튼: 짧은 눌림/반동, 마우스 호버, 키보드 포커스. 공격은 금색 돌출 버튼,
  버리기는 붉은 버튼. 공격 확정 중에는 잠금 색과 비결정형 진행선을 표시한다.
- 카드를 ID별로 유지해 선택/해제 시 자연스럽게 이동한다. 다른 카드의 DOM이나
  포커스를 매 클릭마다 교체하지 않는다. 새 카드만 24ms 간격으로 들어온다.
- 실제 버리기 성공 뒤에만 선택 카드 복사본이 퇴장한다. 복사본은 inert,
  aria-hidden, pointer-events:none이며 ID/조작 속성이 없다. 종료/취소 시 제거.
- 실제 공격 확정 시 득점 카드와 계산 연쇄에 짧은 강조. 기존 pending.applied
  전환 시점에만 버튼을 `적중! · N 피해`로 바꾸고 피해량/적 체력을 강조한다.
  기존 캔버스 숫자 위에 또 숫자를 겹쳐 넣지 않는다. 원본 포즈·투사체는 그대로.
- 골드/체력/횟수/예상 피해는 값이 바뀔 때만 작은 강조. 팝업은 새로 열릴 때만
  진입하며 선택/구매 때마다 재시작하지 않는다. 화면 전체 흔들림/번쩍임 없음.
- 별도 UI 모듈에는 엔진/게임 상태/RNG/게임 실행 콜백을 전달하지 않는다.
  애니메이션 완료로 공격·버리기·충전을 실행하지 않는다. 입력 지연도 추가 안 함.
- OS 모션 감소 설정 시 CSS/JS 모션 모두 생략하고 실행 중 모션도 취소한다.
  메뉴/일시정지는 배경 모션을 취소하며 복귀 시 지연된 적중 표시가 없다.

브라우저 검사: 원래 시드61의 실제 입력, 카드 노드 동일성/선택 transition,
버튼 animation/8장 교체/복사본 안전성·정리, 적중 숫자=실제 피해, 시각 효과 중
자원·RNG 불변, 도움말 정지, 실시간 모션 감소 전환, 모바일320/390/760/844.
기존 포커58~63·아카이브 브라우저, 단위/아트 검사도 유지한다.
검사 통과는 재미나 미적 품질에 대한 사용자 승인을 뜻하지 않는다.
