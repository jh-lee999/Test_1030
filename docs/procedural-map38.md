# 절차 생성 아공간 v38

## 요청과 범위

몇 가지 발판 템플릿을 선택하던 v37에서 로그라이크식 맵 생성으로 전환.
원작 버터/몬스터 아틀라스와 모션은 변경하지 않았다. 기존 숲 배경 2장 위에
지형별 발판, 구덩이 표시, 등불/기둥/버섯/꽃을 코드로 렌더한다.

## 두 단계 생성

1. **구역 그래프**: 7개 깊이의 유향 비순환 그래프. 시작/보스는 1개,
   중간 깊이는 2~3개 노드. 가까운 갈래로 분기하며 이후 합류한다.
   모든 노드에 들어오는 길/나가는 길이 있고 모든 경로는 보스로 이어진다.
   전투/정예/보물/휴식방의 종류와 지형이 미리 정해져 지도에서 확인 가능하다.
   한 깊이에서 선택하지 않은 갈래로 돌아가지는 않는다.
2. **방 내부 지형**: 지형 프로필의 길이/너비/고저차 범위 안에서 주 경로를
   확장하고, 일부 구간에 위쪽 샛길을 더한다. 발판은 고정 프리셋 좌표가 아니다.
   출구는 주 경로 끝 발판의 실제 높이에 놓는다. 적은 시작 지점에서 최소
   340px 떨어진 지지 발판에만 생성한다. 보물/회복 시설과 전리품에도 발판 ID를
   부여해 도달 가능성을 검사한다. 보스방은 넓은 아레나 규칙을 사용한다.

프로필: 햇살 숲길 / 나무 위 샛길 / 무너진 회랑 / 반딧불 골짜기.
대체되는 것은 지형 생성이며, 원작 배경 자체를 재생성한 것은 아니다.

## 난수 / 재현

`seedNumber`는 문자열을 32bit 시드로 정규화한다. 생성 규칙 버전은 38.
그래프, 노드별 지형, 전투 확률, 아이템 뽑기의 RNG를 분리한다. 총을 몇 번
쐈는지나 아이템 RNG 소비량이 다음 방 지형을 바꾸지 않는다. 같은 시드와
같은 노드 ID는 같은 방을 만든다. 새 버전의 생성 규칙까지 영구적으로 동일한
맵을 보장하는 것은 아니므로 규칙을 바꿀 때 버전도 올려야 한다.

시작 화면 시드 입력 / URL `?v=rogue38&seed=ROGUE-38` / 지도 시드 표시.
새 맵으로 시작과 같은 시드로 재도전 버튼은 별도다. 세이브 시스템은 아니다.

## 진행 안전성

- `platformer-physics.js`의 중력, 초기 점프 속도, 기본 이동속도, 가속/감속,
  1/120초 스텝, 한 방향 발판 착지를 게임과 검증기가 공유한다.
- `findJump`는 시작/착지 후보점에서 실제 점프를 시뮬레이션한다. 모든 발판을
  충돌 검사하므로 중간 발판에 잘못 걸린 궤적을 통과 처리하지 않는다.
- 시작점에서 모든 발판으로 가는 경로와 각 발판에서 출구로 나오는 경로를
  각각 탐색한다. 경로에는 시작 X, 조준 X, 프레임 수를 증거로 보관한다.
- 초기 이동속도와 1단 점프만으로 검사한다. 2단 점프/대시/속도 아이템은
  통과 전제조건이 아니며 여유 수단이다. 전투 위험/회피 능력까지 증명하지는 않는다.
- 실패하면 시드 파생값으로 8회까지 재생성한다. 그래도 실패하면 같은 지형
  프로필의 단순한 안전 경로를 생성해 다시 검사하며, 불합격 방을 배포하지 않는다.
- 낙하는 마지막 지지 발판의 안전한 중앙 쪽 위치로 복귀. 기존 피해 무적 규칙을
  존중하며 이동/점프/공격 상태를 정리한다. 높은 발판에서는 세로 카메라도 따라간다.
- 왕짱돌은 실제 생성된 발판에 반사되며 구덩이로 완전히 떨어지면 사라진다.

## 방 종류

- 전투: 적 전멸 → 기존 14종 중 아이템 1개 선택 → 출구에서 경로 선택.
- 정예: 강화된 적, 저학년/고학년 참고서 선택지 보장.
- 보물: 전투 없음. 상자 가까이에서 F / ↓ → 아이템 선택. 중복 수령 불가.
- 휴식: 샘 가까이에서 F / ↓ → 최대 체력의 40% 회복. 방마다 1회.
- 보스: 보스 처치/아이템 선택 후 출구에서 탈출.

지도 열기 자체는 전투를 일시정지한다. 단순 지도 확인으로 다른 방에 이동할
수 없으며, 현재 방 보상 완료/출구 접촉/경로 선택 상태/연결된 노드 검사를 모두 거친다.

## 검증

- 1,000개 시드의 모든 14,006개 방에서 지형/적/전리품/시설/출구 검사 통과.
  2,084가지 방 너비, 16가지 발판 개수. 재생성 한도를 넘은 12개는 안전 대체 경로.
- 그중 4,994개의 정방향/출구 복귀 점프 증거를 실제 게임 `tick`으로 재생해 착지 확인.
- 숫자/문자 시드 재현, 전투 RNG와 지형 분리, 그래프 도달성/합류,
  잘못된 지형 거부, 방 건너뛰기 방지, 보물/회복 1회성, 낙하 복귀 검사.
- Chromium: 실제 시작/연사/2단 점프/대시/왕새총/지도 일시정지,
  7단계 경로 선택, 보물·정예·휴식·보스, 같은 시드/새 시드 재시작,
  터치 동시 이동·공격 및 320/390/844px 경로 버튼 범위/선택 확인.
  전 구역 UI 흐름 검사는 전투 시간을 줄이기 위해 적 HP를 fixture에서 0으로
  만든다. 사람이 무보정으로 전투를 전부 클리어했다는 의미는 아니다.

한계: 전방 진행형 지도이며 자유 왕복/비밀방/상점/영구 성장/저장은 아직 없다.
방 지형이 반복되지 않을 확률을 높인 것이지 무한히 고유한 배치를 수학적으로
보장하는 것은 아니다. 보스 패턴과 원작 몬스터 종류는 v37을 유지한다.
