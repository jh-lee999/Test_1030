## 원작 사도 잔상

원작 모델/스킬 참조와 팬 게임 각색은 [REFERENCE.md](../assets/trickcal-elites71/REFERENCE.md)에
분리했다. 원작 보스AI나 현재 라이브 계수를 재현했다고 주장하지 않는다.
출현45/100/155초 순환은 벨벳/에르핀/셰이디.100초 에르핀 수호자가 추가되며,
동시 일반 사도 잔상은2명 이하. 필수 봉인 후 최종 수장은 셰이디다.
같은 순간 두 잔상이 동시에 고유 공격 예고를 시작하지 않도록 예약한다.

| 잔상 | 예고와 실제 공격 | 공략 |
| --- | --- | --- |
| 셰이디 |1.1초 고정 도착점 표시 → 안전한 위치로 순간이동 →82px 안6연격/1.2초 | 도착 표식에서 벗어나기, 추적 재조준 없음,1.3초 후딜 |

| 에르핀 |0.95초 고정 조준선 →0.17초 간격 마력탄4발 | 발사 후 유도 없음, 엄폐물에 차단,1.25초 후딜 |

원작 전신 포즈와 각 클립의 공통 원점을 사용한다. 사도 소스 배율.14를 고정하고,
모든 포즈에 일반1.05/최종1.35 표시 배율을 공유한다. 공격 활성/후딜에 맞춰
소스 클립의 시간 창을 일관되게 재시간화하며 개별 그림을 맞춤/자르지 않는다.
셰이디 원본의5개 정확한 빈 프레임은 차원 이동 전환이다. 의도하지 않은 빈 프레임은
검사 실패이며, 게임의 진입/타격 시점에는 보이는 소스 구간을 사용한다.

## 저장과 비용

새 키 `butter.survivor71.v1`은 처음 없을 때만 유효한 v69 연구/조각/기록 프로필을
가져온다. 진행 중인 판은 기하/규칙이 달라 이식하지 않으며 원래 키를 지우거나
정산하지 않는다. 시작 화면의 이전 버전 링크에서 계속할 수 있다. 이미 새 키가 있으면
구버전 프로필을 다시 가져와 조각/보상을 복제하지 않는다. 두 버전은 이후 별도 진행이다.

이미지는 필요한 사도10클립만 로드한다(명목 디코딩 바이트 약76.3MiB, 브라우저/GPU
전체 측정치 아님). 총 이동 시트41.25MiB 등 다른 기존 시트의 메모리는 별도다.
지형 캐시는 여전히48청크/12MiB 상한.240명 스트레스 검사는 렌더 시간 표본이며
모든 기기에서의 FPS·전체 시뮬레이션·메모리 보장은 아니다. 이미지 실패 시에도 시작/
선택/전투는 유지된다. 작은 화면은 보스바/시계가 겹치지 않게 별도 배치한다.
