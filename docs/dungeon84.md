## 조합의 정확한 제한

- 거울+낫: 기존 `plan.bounces`만큼 저학년/낫 탄환도 벽 반사. 적중 무작위 도탄 예산과
  별도로 소비하며, 벽에서 가장 가까운 적으로 자동 조준하지 않는다.
- 빙결+벨트: 돌아오는 **본체**가 맞았을 때 한 번, 반경100 냉기 파동.
  일반0.7초/보스0.15초 빙결, 자식 탄환/가는 탄환은 이 추가 파동을 만들지 않는다.
- 폭죽+종: 폭탄 설치 순간 조합을 고정한다. 폭발 뒤 네 방향에1.4초·반경28 불씨.
  안전 바닥에 놓고 불씨35개 상한. 불씨에서 폭탄/새 불씨가 재귀 생성되지 않는다.

모든 스탯 아이템을 지우거나 강제 조합만 주는 방식은 아니다. 스탯/경제/위험/학년 아이템도
여전히 추첨한다. 황금방 초반 보장은 **제시 이력**이며 강제 획득·무료 시작템이 아니다.
이미 모든 유효 기믹을 가진 경우 등 후보가 없다면 남은 합법 풀을 사용한다.

## 저장과 이전 판

`butter.dungeon84.v1`에 새 판을 저장한다. 예전 `butter.dungeon80.v1`의 진행 중 판과
볼륨 키는 쓰거나 지우지 않는다. 발견/해금 프로필만 첫84 시작 때 가져온다.
이전 루트의 정확한 HTML은 `dungeon83.html`이며 타이틀에서 링크한다.
옛 엔진/원작 그림/소스 모션/발 기준/좌우 반전/머즐/발사 타이밍은 변경하지 않았다.
83 진단 해시도 그대로이고, 옛 테스트는 진입 URL만 보관본으로 바꿨다.

## 검증 방식

`test/dungeon84.test.js`는1,000시드×3층의 연결·보스 거리·끝방·특수방 할당·최대 인접
비밀방·진짜 순환을 검사한다.90층 전체 전투방의 엄폐 연결·문 여유·스폰 거리/간격·
위협 예산·모든7원형/5역할/4크기,500판의 첫 두 황금방 기믹 보장도 확인한다.
일반 증원 중간 저장/일시정지/정확 재현·중복 충전 방지·선택 수호자·3층 전환/정산·
원작/83 소스 핀·후보 예약·조합·120회 수동 액티브 교체·손상 저장 거부를 포함한다.
추가 회귀 테스트는 수동 발사/추적 지연/무작위 적중 도탄/나무상자7공격 경로/고속 충돌이다.

브라우저 검사는 시작·마우스/키보드 사격·이어하기·학년 큐·큰 방·퍼즐/재봉·수호자
원작 이미지 실제 로드/이름·충전된 액티브 F교체·증원 대기시간 재시작·상점 실제 결제·
지도 기록·390/568px 듀얼 터치·이미지/저장 실패 경로를 포함한다.
방/아이템 상태를 놓는 검사는 명시적 **fixture**이며 정상 획득/실제 승리로 표시하지 않는다.
`playtest-dungeon84.mjs`만 게임 상태를 읽고 실제 DOM 입력으로3전투를 진행한다.

`check-dungeon84-pressure.mjs`는 같은24개 깊은 방/장비/진입을 놓고 오른쪽 고정 사격,
제자리 정밀 조준, 회피 조준을 비교한다. 추가 무적/스탯 보정은 없지만 전정보 검사
프로그램이지 사람 플레이가 아니다. `balance-dungeon84.mjs`의 긴 판 결과도 시간 제한,
죽음, 유효 저장 실패, 컨트롤러 정체를 분리한다. 자동 결과를 인간 난이도/재미/판매 품질의
증명이라고 주장하지 않는다. 최종 수치와 실행 증거는 [diagnostics](dungeon84-diagnostics.json)에 기록한다.
긴 판 정책은 보조 액티브/폭탄을 최적 사용하지 않는다. 따라서 그 사망률은 인간 승률의 추정치가 아니다.

성능은 동시 테스트/프로파일러 없이 일반/대형 방 각각 새 헤드리스 브라우저에서7초를
측정한다. 원작 셀 캐시24MiB 상한, 입장 CPU 시간, rAF 간격과 일시정지 렌더 제출 시간을
기록한다. 사용자 기기의 FPS나 GPU/RAM 실측으로 바꿔 말하지 않는다.

```sh
npm test
node tools/check-dungeon84-pressure.mjs
node tools/balance-dungeon84.mjs
# 별도 로컬 HTTP 서버, Playwright/Chromium 경로 설정 후:
node tools/check-dungeon84-browser.mjs
node tools/check-dungeon84-rules-browser.mjs
node tools/check-dungeon84-crates-browser.mjs
node tools/check-dungeon84-decisions-browser.mjs
node tools/playtest-dungeon84.mjs
# 무거운 다른 검사가 끝난 뒤 단독 실행:
node tools/check-dungeon84-performance.mjs
```
