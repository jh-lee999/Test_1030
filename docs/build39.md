# v39 · 누적이 보이는 버터 빌드

사용자가 말한 누적은 **같은 판 안에서의 아이템/학년 누적**이다. 새 판에도
남기는 영구 성장은 이번 작업에 포함하지 않는다. 버터 원작 그림과 모션,
v38 시드/지형/분기 생성 규칙은 그대로 유지한다.

## 먼저 확인한 문제

v38의 `applyItem` 자체는 누적되고 있었다. 저학년 책 두 개는 Lv.1→2→3,
공격력 +20% 아이템 두 개는 15→18→21.6이고 방 이동에도 유지됐다.
그러나 학년으로 계산한 유도 성능을 횡스크롤 탄환에서는 사용하지 않고
고정값 7을 썼다. 저학년 피해도 고정 배율이고, 연쇄 중 남은 수명 부족과
선회 시 감속으로 학년이 늘어도 다음 적에 도착하지 못할 수 있었다.
보유 수량, 실제 적용 능력치, 획득 전후 비교도 없었다.

v39에서는 보유 개수로 기본값부터 능력치를 재계산한다. 이전 아이템 효과가
후속 획득에 덮어써지지 않고, 각인 보너스도 한 번만 적용된다.
실제 탄환에 학년별 유도 성능/피해/연쇄를 연결하고 속도를 유지한다.
연쇄 성공 시 남은 수명 최소 1.3초를 보장한다. 관통탄은 한 틱 안에 여러
적을 지나도 이동 순서대로 충돌하고, 왕짱돌은 적의 전신 사각형과 충돌한다.

## 조작 / 확인 방법

- **I / 가방 버튼:** 보유 아이템 ×개수, 각인 문턱, 학년 계산 출처, 실제 적용
  능력치 31개 항목. 확인 중 전투가 멈춘다.
- 보상/상점 카드: `보유 ×1 → ×2`, 스탯 전후 수치, 각인 개수 변화,
  2·4세트 활성 여부. 카드에는 주요 변화 3개, 전체는 가방에서 확인한다.
- **B / 가방 안 상점 버튼:** 현재 방의 전투/보물/쉼터 이용을 마친 뒤 개방.
  **I 또는 Esc**로 가방을, **B 또는 Esc**로 상점을 닫는다.
- 모바일에는 세로 스크롤 가능한 전체 화면 패널을 사용한다.

## 성장 규칙

공격력·이동속도·탄속은 아이템의 `(1 + 증가율)^개수`로 곱한다.
공격 속도는 초당 발사 횟수가 표기 증가율만큼 오르도록 공격 간격을 나눈다.
최대 체력·학년·치명타 확률 등은 더한다. 최대 체력 아이템은 **늘어난
최대 체력만큼만** 현재 체력도 회복한다. 나머지는 임의로 체력을 채우지 않는다.

| 각인 | 2개 | 4개 (2개 효과도 유지) |
| --- | --- | --- |
| 명사수 | 치명타 +10%p | 치명타 피해 +50%p |
| 탄성 | 추적탄 추가 도약 +1 | 추가 탄환 +2, 각 55% 피해 |
| 학구열 | 스킬 쿨감 +10%p | 저·고학년 +1, 스킬 피해 +25%p |
| 불꽃놀이 | 적중 시 2초 화상, 초당 공격력 15% | 처치 시 반경 100px에 공격력 80% 폭발 |
| 포근함 | 방 입장 보호막 +18 | 방어 +25, 처치 시 체력 +2 |
| 질주 | 대시 쿨타임 -20% | 대시 접촉 시 공격력 140%, 적당 대시당 1회 |

각 아이템에는 각인 2개가 있다. **동일 아이템 4개도 4세트**를 활성화한다.
문턱을 넘어 더 모아도 세트 보너스는 다시 더하지 않지만 아이템 자체는 누적된다.
학구열 4세트의 학년 +1은 가방에 별도 출처로 표시한다.

저학년 발동 확률은 `min(85%, 13% + Lv×5.5%p + 발동 보너스)`.
랜덤이 계속 실패해도 `max(3, 7-floor(Lv/2))`번째 실제 사격에는 발동한다.
추적탄 피해는 `공격력 × (1.15 + Lv×0.1) × 스킬 피해 배율`, 추가 도약은
`Lv + 도약 보너스`, 유도 성능은 `7 + Lv×0.8`.
**v40 사용자 요청으로 수정:** 평생 재타격 금지를 제거하고 직전에 맞힌 적만
제외한다. 적중한 적 중심에서 480px 안의 가장 가까운 살아 있는 적으로 튕기며
`A → B → A` 왕복을 허용한다. 다른 적이 없으면 종료하므로 단독 적을 즉시 다시
맞히지는 않는다. 탄환당 최대 적중은 `1 + Lv + 도약 보너스`다. 겹쳐 있는 적도
적중 사이 최소 0.08초를 두고, 실제 충돌 지점에서 다음 목표로 날아간다.
목표가 도중에 죽으면 범위 안에서 다시 찾으며 추가 횟수를 이중 차감하지 않는다.
연쇄 구간 수명은 최소 1.3초 또는 남은 이동 시간+여유 시간으로 갱신한다.
일반 관통탄의 동일 대상 1회 제한과 캐릭터 모션/물리는 변경하지 않는다.
Lv.3에 추가 1발, Lv.5부터 추가
2발이고 추가탄은 주 탄환의 55% 피해다. 아이템 다중탄과 합산한다.

고학년 왕짱돌은 `공격력 × (2.5 + Lv×0.55) × 스킬 피해 배율`,
`4.5 + Lv×0.8`초, 반경 `40 + Lv×4`px. Lv.3부터 반대 방향 짱돌도 발사
(65% 피해). 기본 재사용 13초에 쿨감을 적용하며 사용 중 무적이다.
이전 구현처럼 방 이동 시 무적/짱돌은 종료된다.

방어 피해 감소는 `방어/(100+방어)`. 보호막은 감소 후 피해를 먼저 흡수하고
방 입장 시 충전한다. 새 보호막 능력치를 얻으면 증가분만 채운다.
흡혈은 직접 타격의 **실제 HP 손실** 기준(오버킬 제외). 화상과 처치 폭발은
흡혈·치명타·재점화를 유발하지 않는다. 화상은 2초 갱신형, 0.5초마다 피해.
처치 폭발의 연쇄 처치는 허용하지만 같은 적 처치 보상은 한 번만 준다.

상한: 치명타 80%, 쿨감 65%, 흡혈 15%, 방어 200, 관통 +6명, 아이템 추가탄
+6발, 공격 간격 최소 0.08초. 상한에서도 보유 개수는 쌓이지만 실제 효과는
더 늘지 않으며 카드/가방에 이를 표시한다. 저학년 발동 확률 상한은 85%.

## 보상과 돈

보상 3개 중 학년 책 최소 1개를 보장하며 정예는 저·고학년 책을 모두 보장한다.
나머지는 일반/희귀/영웅 가중 추첨. 진행도에 따라 고등급 비중이 증가하고,
이미 모으는 각인과 맞는 아이템은 가중치 1.4배(보장은 아님).
보상 재추첨은 방당 2회, 8 / 14 G. 학년 보장은 유지되므로 책은 재등장할 수 있다.

상점은 방마다 3개, 일반 15 / 희귀 24 / 영웅 38 G. 각 진열은 한 번만 구매하며
10 G로 진열 전체를 교체(방당 3회)한다. 다른 방이나 재진열에서 같은 아이템이
나오면 다시 사서 누적할 수 있다. 상점 RNG는 전투·전리품·지형 RNG와 분리한다.
상점은 새 NPC 그래픽이 아닌 메뉴 방식이다.

체력 손실 없는 전투방 클리어 보상은 8 G와 스킬 쿨타임 3초 회복, 방당 1회.
보호막으로만 막은 피해는 허용하므로 **무피격 보상이라고 부르지 않는다**.
보물/휴식방에는 이 추가 보상을 지급하지 않는다.
