# v59 · 유물 서순

요청: 발라트로처럼 유물의 배치 순서가 실제 피해에 영향을 주게 만들기.
기존 v58은 소유 여부만 검사하여 항상 `+배수 → 곱배수 → 최종 고무줄`로 계산했다.
이제 `g.relics` 배열 순서가 실제 유물 단계의 실행 순서다. 자동 정렬하지 않는다.

## 계산 단계

1. 족보 기본 칩/배수와 누적 훈련 레벨.
2. 득점 카드마다 기본 칩과 카드 단계 효과. 리본은 같은 숫자 카드를 유한1회
   재발동하고, 별사탕/날씨는 맑음도 매 발동에 반응한다. 카드 단계의 유물은
   그 안에서 슬롯 순서를 따른다. 카드 무한 재발동이나 이동 시 충전은 없다.
3. 유물 단계: 슬롯1→2→3→4. **더하기와 곱하기를 종류별로 재정렬하지 않는다.**
   - 꼭 쥔 행운: 하트의 총 발동 횟수(리본 포함)×0.5를 **자신의 슬롯 위치에서**
     배수에 더한다. v58 카드 단계에서 더하던 효과를 이 단계로 옮겼고 설명도 변경.
   - 빈 주머니: 버리기0이면 자신의 위치에서 배수+3.
   - 고무줄: 자신의 위치에서 현재 배수×1.5. 뒤의 더하기를 미리 증폭하지 않음.
   - 플러시/스트레이트 유물, 옐로카드, 상처, 메이스의 배수도 자기 위치에서 곱함.
   - 황금 방울은 자신의 위치에서 칩을 추가. 칩끼리 더하는 효과나 곱셈끼리는
     서로 교환해도 값이 같을 수 있다. 모든 이동에 가짜 피해 보너스를 붙이지 않는다.
4. 적 빈틈/방패, 원페어의 방패 파괴, 처형/실제 피해 기준 흡혈.

카드 단계/유물 계산/적중 후/전투·피격 배지를 구분한다. 보호막이나 위기 회복을
배치만 바꾸었다고 재충전하지 않으며, 적중 후 효과를 임의로 곱배수 앞에서 중복
계산하지 않는다. 이는 이 게임용 각색이고 원작 트릭컬의 유물 계산을 재현한 것이 아니다.

## 정확한 예

족보 배수2, 칩20인 하트5 두 장(서로 다른 복제 카드 ID)을 가정:

| 배치 | 계산 | 피해 |
| --- | --- | --- |
| 꼭 쥔 행운 → 고무줄 | 20×((2+1)×1.5) | 90 |
| 고무줄 → 꼭 쥔 행운 | 20×(2×1.5+1) | 80 |
| 버리기0, 빈 주머니 → 고무줄 | 20×((2+3)×1.5) | 150 |
| 버리기0, 고무줄 → 빈 주머니 | 20×(2×1.5+3) | 120 |

리본/하트/빈 주머니/고무줄의24가지 순열도 별도의 순차 산술 기준과 대조한다.
최대 피해 자동 선택은 새로운 배치로 **모든 합법 족보를 다시 검색**한다.
단순히 선택된 족보의 숫자만 바꾸지 않는다. 테스트의 다른8장 예에서는 순서 변경에
따라 투페어261에서 원페어235가 새로운 최대가 되는 경우까지 검증한다.

## 조작과 불변 조건

- 전투의 유물 바와 상점 유물 바 모두 같은 슬롯 순서. 데스크톱 드래그,
  좌우 화살표, 키보드 버튼 조작, 모바일44px 이상 터치 버튼.
- 화살표의 숫자는 **현재 패의 최대 실제 피해 변화**. 이동 후 배치 전/후 피해 표시.
  상점에서는 다음 패를 알 수 없으므로 가상의 다음 전투 피해를 표시하지 않는다.
- 이동은 삽입 이동. 1번을4번으로 옮기면 나머지 세 개가 앞당겨진다.
- 이동은 무료. 돈/HP/카드/버리기/공격/충전/RNG는 그대로. 전투 사이 배치 유지.
  새 유물은 끝에 추가, 교체는 선택한 슬롯 그대로, 새 런은 초기화.
- 선택/상점/초기 선택 단계만 허용. 공격 확정부터 적중/반격까지, 일시정지,
  승리/사망에서는 잠금. 이미 확정한 `result.relicOrder`/계산 단계/피해는 고정.
- 프리뷰·이동 후보·설명 표시에서 충전/체력/방어를 실제 적용하지 않는다.
  실제 적중 시 한 번 적용하는 기존 타이밍/렌더러/원작 에셋은 변경 없음.

## 검증

- order59 단위8개: 순차산술/24순열/유한재발동/충전프리뷰/잘못된 이동/
  모든 잠금 단계/공격 스냅샷/전투간 유지/슬롯교체/최대족보 변경.
- 명시적 상태 주입을 사용하는 order59 브라우저: 실제 이동 버튼으로90↔80,
  진짜 드래그, DOM 갱신 후 Enter 역이동, 계산창 슬롯 순서, 실제 적중90,
  잠금/모달 포커스/상점무료이동/다음전투유지, 320·390·760·844폭 터치.
  이것을 정상 획득한 유물의 전체 런 플레이로 주장하지 않는다.
- 별도의 poker58 브라우저는 원래 자원·실제 버튼으로6전투를 진행한다.
  신규 족보/덱 편집/유물 연쇄와 이전 주사위·횡스크롤·핀볼 검사도 유지한다.
- 소스 아트/스프라이트 앵커는 변경하지 않음. 버터 원작 모션/투사체 코드는 그대로.
  검사의 통과가 사람의 재미나 게임 완성도를 입증하는 것은 아니다.

v58의6전투/자원/상점/13족보 규칙은 그대로다. `poker58.html`은 현재 코드로
들어오는 별도 진입 주소이므로 새 슬롯 UI도 같이 갱신했다. v57 이하 보존본은
원문과 엔진 모두 그대로다.
