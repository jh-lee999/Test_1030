# 버터 모델링 기준 자료

이 문서는 31번 3D 시안 제작 기록입니다. 최신 작업의 외형 기준은 [고정 기준 문서](../art/BUTTER_CANON.md)를 따릅니다. 3D 결과물은 승인된 외형 참조가 아닙니다.

기준 우선순위는 승인한 `assets/butter-2d-study.png` → 사용자의 복장·해부 구조 수정 → 원래 버터 스프라이트 → 새로 만든 방향별 보완도입니다. `turnaround.png`의 정면·측면·후면은 승인 시안을 바탕으로 생성한 작업용 자료이며, 공식 설정화가 아닙니다.

## 정합 기준

시트의 바닥 Y=805, 정면 중심 X=390, 250px=1 Blender 단위로 통일합니다. 높이는 `z=(805-y)/250`입니다. 정수 픽셀 측정의 오차와 원 그림의 원근이 있으므로 실측 도면과 같은 정밀도를 주장하지 않습니다. 모델 생성기는 `spec.json`을 직접 읽습니다.

| 기준점 | 시트 Y | 모델 Z |
|---|---:|---:|
| 정수리 | 103 | 2.808 |
| 눈 중심 | 280 | 2.100 |
| 턱 | 375 | 1.720 |
| 허리 | 514 | 1.164 |
| 반바지 밑단 | 614 | 0.764 |
| 무릎 | 686 | 0.476 |
| 발바닥 | 805 | 0.000 |

## 형태와 구조

- 얼굴: 좌우로 넓고 아래가 둥근 사각형. 얕은 앞면에서 볼 가장자리로 부드럽게 말려 들어갑니다. 돌출된 코와 뾰족한 턱은 만들지 않습니다.
- 앞머리: 넓은 면 세 덩어리가 겹치며 끝이 가늘어집니다. 뒷머리는 연결된 넓은 덩어리와 물결형 밑단으로 구성합니다.
- 귀: 머리 양옆 위에서 붙어 아래로 접히는 강아지 귀. 귀 뿌리 리본과 중앙 리본을 구분합니다.
- 복장: 흰 반팔 블라우스 위에 노란 앞치마. 앞쪽 리본과 주머니, 뒤쪽 교차 끈. 뒤는 열려 있어 분홍 반바지가 보입니다.
- 꼬리: 골반 뒤 중심에서 시작한 뒤 옆으로 휘어집니다. 가방이나 옆 골반에 붙이지 않습니다.
- 새총: 해부학적 오른손. 정면에서는 화면 왼쪽, 후면에서는 화면 오른쪽입니다. 가방은 왼쪽 골반입니다.

## 추정과 충돌 처리

승인 그림은 정면 직교 투영이 아니므로 얼굴 깊이·뒤통수·머리카락 단면은 측면 보완도에서 추정했습니다. 측면 보완도는 가려질 소품도 보여주므로 실제 모델은 손과 골반의 좌우 관계를 우선합니다. 정면·후면 시트의 각 높이는 맞추되, 그림의 모든 선을 입체의 동일 지점으로 취급하지 않습니다.

## 재현과 검토

`tools/build_butter_aligned31.py`가 이 자료를 읽고 Blender 원본, GLB와 방향별 렌더를 만듭니다. Blender 안에는 기준 시트와 설명을 포함합니다. 웹 검토 페이지는 정면 렌더와 정면 도안을 같은 좌표계로 겹쳐 볼 수 있습니다. 이 버전은 외형 검토용이며 게임용 동작은 포함하지 않습니다.
