## 반복 순서

1. 화면/정보 계층 재구성: 전투와 결정을 한 화면에, 상세는 펼쳐서.
2. 저장·재개·설정·기록: 매 행동을 보호하고 재진입을 막지 않기.
3. 전투·상점·성장 연결: 적 예고, 실제 투자 비교, 빌드 방향, 결과 피드백.
4. 실제 플레이/실패 상황 반복 검사 → 발견 문제 수정 → 배포 확인.

이 문서는 작업 중 체크리스트다. 미완료 항목을 완료라고 주장하지 않는다.

심층11/18(리본2/6·무늬6/6·연속3/6). 작은 족보 방어와 보스 장막을 실제 입력으로
검증했다. 빌드 편차/장기 반복 재미와 처음 보는 유저의 이해도는 추가 관찰이 필요하다.
