# 품질 목표 · 상업용 소규모 게임에 준하는 플레이 완성도

사용자 목표: 판매는 하지 않지만 돈을 받고 제공해도 납득할 완성도까지 반복 개선.
원작 팬 에셋의 상업 이용 허가를 뜻하지 않으며, 테스트 성공만으로 재미를 인정하지 않는다.

## 출시 판단 기준

- [x] 첫 플레이: 카드 선택=버리기, 자동 최강 공격, 턴/전투 횟수 안내와 구분 표시.
- [x] 화면: 데스크톱1366×768에서 전투·손패·교체·공격이 스크롤 없이 보임.
- [x] 모바일:320~844폭에서 가로 넘침/가려진 필수 조작/44px 미만 주요 타깃 없음.
- [x] 판단: 현재 피해·실제 반격·다음 행동·유물 순서·투자 결과를 구매 전에 확인.
- [x] 지속성: 새로고침/탭 이탈/공격 도중 재접속/손상된 저장/저장 차단에도 정상 진행.
- [x] 마무리: 승패 원인·만든 빌드·전투 기록·같은 시드 재도전·새 판이 이어짐.
- [x] 접근성: 키보드/터치, 모션 감소, 음량/소리 설정, 포커스 유지와 팝업 제목 대비 검사.
- [x] 신뢰성(로컬): 일반/심층 실제 입력6전투, 단위/브라우저/아트 검사 통과.
- [ ] 배포: GitHub Pages 최종 커밋 배포 확인.
- [ ] 재미: 여러 빌드·시드에서 첫5분/전체 런을 직접 검토. 자동 승률=재미 아님.

## 반복 순서

1. 화면/정보 계층 재구성: 전투와 결정을 한 화면에, 상세는 펼쳐서.
2. 저장·재개·설정·기록: 매 행동을 보호하고 재진입을 막지 않기.
3. 전투·상점·성장 연결: 적 예고, 실제 투자 비교, 빌드 방향, 결과 피드백.
4. 실제 플레이/실패 상황 반복 검사 → 발견 문제 수정 → 배포 확인.

이 문서는 작업 중 체크리스트다. 미완료 항목을 완료라고 주장하지 않는다.

v65 구현/검증 상세는 [release65.md](release65.md). 최종 자동 표본은 일반18/18,
심층11/18(리본2/6·무늬6/6·연속3/6). 작은 족보 방어와 보스 장막을 실제 입력으로
검증했다. 빌드 편차/장기 반복 재미와 처음 보는 유저의 이해도는 추가 관찰이 필요하다.
