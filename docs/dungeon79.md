# v79 — 보상을 찾아다니는 규칙

시작방의 무료 유물과 ‘첫 선물’ 선택을 없앴습니다. 새 탐사는 기본 무기로 출발하며,
다음 층에서도 무료 유물을 주지 않습니다. 층 이동 시 보유 유물·무기는 유지됩니다.
이미 먹은 유물을 소급 제거하거나 캐릭터의 원작 그림을 바꾸지 않습니다.
이번 수치는 사용자의 획득 경로 지시를 구현한 팬게임 수치입니다.
PokeIsaac의 실제 드롭률·열쇠 규칙을 검증해 그대로 복제했다는 주장은 아닙니다.

| 획득 경로 | 결과 |
| --- | --- |
| 시작방 / 일반 전투방 클리어 | 확정 유물 없음 |
| 황금방 | 단일 유물 하나 확정, 기존처럼 입장 열쇠1개 |
| 보스 처치 | 단일 유물 하나 확정 + 기존1·2층 증강 선택 |
| 나무상자 파괴 |3% 유물 /45% 동전 /7% 폭탄 /45% 없음 |
| 황금상자 개방 |30% 유물 /70% 동전3–6개와 열쇠·폭탄·14HP 중 하나 |
| 일반 전투방 황금상자 배치 | 방별20%, 전투가 끝나야 개방 가능 |
| 비밀방 / 보관실 / 도전 성공 | 확정 유물 대신 황금상자1개 |
| 상점 / 최대 HP 계약 | 기존 유료 구매·교환 유지 |

황금상자 개방은 근접 F와 열쇠1개가 필요합니다. 그냥 밟거나 폭탄을 쓰면 열리지 않으며,
열쇠가 없거나 아직 전투 중이면 비용·드롭 RNG를 소비하지 않습니다.
열림을 먼저 확정한 뒤 한 번만 추첨합니다. 유물 후보가 모두 소진되면 보급 보상입니다.
시간제 도전 실패는 상자를 주지 않습니다. 일반 전투 클리어의 보급·동전은 그대로입니다.

확률 성공 후 기존 미보유·해금·희귀도·행운 규칙으로 유물을 추첨합니다.
나무/황금상자의3%/30%는 행운에 의해 변하지 않습니다. 황금방은 기존 황금방 희귀도 비중,
보스는 기존 희귀 보상 비중입니다. 상자의 유물 등급은 기존 일반 추첨 비중입니다.
아직 바닥에 놓인 다른 유물과 ID가 겹치지 않지만, 미획득 유물의 행운/스탯은 적용하지 않습니다.
방 배치 RNG는 아이템·보급 RNG와 분리되어 방문 순서/정보 보기로 상자 배치를 바꾸지 않습니다.

상자에서 나온 유물도 바닥에 남고38px 안을 지나가면 한 번만 자동 획득합니다.
전투 중 드롭도 획득할 수 있습니다. 원하지 않는 트롤템은 피해 지나갈 수 있게 도착점을
플레이어에서84px 이상 떨어뜨리고, 기존32px 연결 내비게이션으로 접근 가능한 곳에 놓습니다.
여러 드롭은68px 이상 분리하고 가까운 것의 설명·대가·실제 수치 미리보기를 표시합니다.
보스 증강과 별개로 유물이 남으며, 원치 않으면 다음 층으로 두고 갈 수 있습니다.
