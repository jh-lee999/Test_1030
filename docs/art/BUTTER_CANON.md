# 버터 외형 기준 — 작업 시작 시 실제 이미지부터 열기

이 파일은 대화 기억 대신 저장소에 남기는 작업 기준이다. 적용 범위는 이
저장소의 버터 작업이며, 모델이나 새 대화가 이미지를 완벽히 기억한다고
가정하지 않는다. 루트 `AGENTS.md`가 이 문서와 실제 기준 이미지를 읽도록
연결한다.

## 기준의 우선순위와 상태

1. 사용자가 명시적으로 말한 최신 수정 사항.
2. **승인한 외형 원본:** `assets/butter-2d-study.png` (시안 28).
3. 복장 구조를 확인할 때 쓰는 원래 버터 자료 및 사용자 제공 이미지.
4. `docs/butter-modeling31/turnaround.png`: 방향별 구조 보완도. 측면·후면에는
   추정이 있으며, 승인 원본을 대체하지 않는다.
5. 새로 생성한 파일은 모두 비교용 후보. 기술 검사가 통과해도 승인으로
   처리하지 않는다.

**승인한 방향별 템플릿:** `assets/butter-2d32/directions.png` — 아래·왼쪽·위·오른쪽
정지 모습 네 장. 사용자가 “이 시안을 틀로 잡아서 절대 왜곡이 안나게”
스프라이트 구현을 요청했다. v28은 외형 기준으로 보존하고, v32는 게임에
적용하는 방향별 기준으로 고정한다. 두 PNG의 픽셀과 해시는 변경하지 않는다.

**v35 게임 적용 후보 (2026-11-03):** `butter-motion.js`,
`assets/butter-2d35/rig.js`, `motion.js`. 소스 좌표는 v33 레이아웃을 유지한다.
양다리의 고관절/무릎 강체 회전, 양손의 장전·놓기, 별도 줄 반동, 골반 중앙
고정점을 중심으로 한 작은 꼬리 흔들림을 합성한다. 보행과 공격 위상은 독립적이다.
새총은 오른손에 고정하고 왼손은 발사 후에도 잠시 뒤에 남으며 줄만 복귀한다.
후면 팔은 머리카락/몸통 뒤에 가리고, 탄환은 움직인 새총 포크 중심에서 나온다.

승인 PNG와 얼굴/머리 상단은 그대로이며, 좌우 반전·비균일 확대·색 필터는 없다.
팔은 둥근 윤곽선으로 연결하고, 공개 전투 아틀라스의 손 두 조각을 사용한다.
생성한 `cleanplate.png`는 **옛 팔/무기에 가려졌던 영역 안쪽만** 복구한다.
전체 캐릭터를 생성 그림으로 바꾸지 않는다. 출처·확인되지 않은 재배포 권리는
[v35 기록](../../assets/butter-2d35/CREDITS.md)에 남긴다.

`butter-2d-motion.html`에서 정지 원본과 실제 게임 렌더러를 비교한다.
동작/보완 그림은 후보이며 사용자의 새 외형 승인이 아니다. 고학년 왕새총 전용
자세와 머리카락/귀의 후속 동작은 아직 없다. 네 방향 원본 모션을 확보한 것도 아니다.
부가 이미지 로딩 실패 시 v34 렌더러로 복귀하며 게임 시작은 막지 않는다.

**실제 모션 참조 확보 (2026-11-03):** 사용자 제공 뷰어의 버터 인게임/Normal을
직접 재생·시각별 분석했다. [모션 참조 기록](BUTTER_MOTION_REFERENCE.md)과
[클립/출처 JSON](butter-motion-reference.json)을 다음 애니메이션 작업 전에 읽는다.
이는 동작 구조와 타이밍의 근거이며 v28/v32의 승인 외형을 대체하지 않는다.
네 방향 원본 모션이나 이동 사격 클립이 모두 확보되었다고 간주하지 않는다.

**v33 피드백 → v34:** 사용자는 “움직이는 모션은 하나도 없다”고 지적했다.
발 높이 9 소스 픽셀(96px 표시에서 약 1.3px)은 너무 작았다. v34는 34px
(약 4.8px) 교대 회수와 발목 위 고정점 중심의 강체 회전을 쓴다. 옆모습에서
가려져 있던 뒷발은 같은 원본의 완전한 앞발 조각을 재사용하여 잘린 발끝이
드러나지 않게 한다. 얼굴·상체 원본은 그대로다. 미리보기는 동작을 먼저
표시하고 정지 원본은 선택해서 펼친다. 동작 줄이기 환경에는 정지 이유와
명시적인 재생 버튼을 보여준다. 실제 재생 루프·일시정지·프레임 진행을 검사한다.

**참조에서 제외:** 26–31의 3D 렌더와 메시. 사용자는 반복해서 기괴함,
스티커처럼 보이는 얼굴, 덩어리 머리카락, 끊긴 옆머리를 지적했다. 배포되어
있거나 리그가 정상이라고 해서 선호한 외형이라는 뜻이 아니다.

## 바꾸지 않을 특징

- 얼굴: 좌우로 넓고 아래가 부드럽게 둥근 형태, 큰 보라/하늘색 눈,
  진한 갈색 곡선 속눈썹, 큰 분홍 볼. 사실적인 코·턱을 추가하지 않는다.
- 머리: 연하고 채도가 낮은 회갈색/베이지에 약한 분홍 기운. 넓게 흐르는
  긴 머리, 말린 앞머리, 정수리 잔머리, 처진 강아지 귀와 노란 리본.
  관자놀이 → 볼 옆 → 어깨 → 뒷머리까지 연결된 실루엣을 유지한다.
- 옆머리가 얼굴 중간에서 잘리거나, 중간에 빈 틈·대머리 영역·떠 있는
  조각이 생기면 수정 대상이다. 전체 실루엣이 셀 안에 있어야 한다.
- 옷은 **흰 반팔 블라우스 + 노란 리본/앞치마**의 두 겹이다. 흰 소매를
  맨살처럼 처리하지 않는다. 뒤쪽 앞치마는 열려 있고 끈이 교차한다.
- 아래는 **분홍 반바지**다. 후면에서도 보이며 노란 치마로 대체하지 않는다.
  크림색 물결 장식, 갈색/연노랑 줄무늬 양말, 분홍 발끝을 유지한다.
- 꼬리는 **골반 뒤 정중앙**에서 시작한 뒤 옆으로 휜다. 왼쪽 골반이나
  가방에 붙이지 않는다. 뿌리가 프레임마다 미끄러져서는 안 된다.
- 새총은 **해부학적 오른손**, 줄을 당기는 손은 왼손. 정면에서는 화면
  왼쪽, 후면에서는 화면 오른쪽이다. 방향 때문에 손을 바꾸지 않는다.
- 강아지 얼굴 가방은 해부학적 왼쪽 골반. 가려져도 자연스럽게 처리한다.
  잘 보이게 하려고 방향마다 소품의 좌우를 바꾸지 않는다.

## 사용자가 지적한 동작 문제도 유지해서 읽기

- 정면만 있는 캐릭터가 아니라 위·아래·왼쪽·오른쪽 모습이 필요하다.
- 걷기는 두 발이 번갈아 나와야 한다. 한 발만 고정해서 흔들지 않는다.
- 발 기준점을 고정한다. 위로 붕 뜨거나 공격 때문에 다리가 계속 벌어진
  상태로 걷는 모습을 피한다.
- 이동 중에도 손의 당기기·놓기가 보여야 한다. 보행과 공격은 독립적으로
  재생해야 하며 정지 사격 그림 한 장으로 보행을 덮어쓰지 않는다.
- 꼬리 움직임은 중앙 뿌리를 유지한 작은 좌우 흔들림이다.
- 아이작처럼 세부를 단순화할 수 있으나 얼굴·복장·소품의 정체성은 유지한다.

## 매번 실행할 절차

1. `npm run check:butter-canon`으로 원본 체크섬을 확인한다.
2. 기준 PNG를 직접 열고 작업할 기존 방향/동작 이미지를 함께 확인한다.
3. 생성 도구에 기준 PNG를 실제 참조 이미지로 넣는다. 문장으로만 기억해서
   새로 그리지 않는다. 3D 렌더를 외형 참조로 넣지 않는다.
4. 같은 배율에서 원본과 후보를 나란히 보고, 96px와 160px에서도 확인한다.
5. 별도 버전으로 저장하고 원본·후보·승인 여부·변경점을 기록한다.
6. 사용자가 새 기준을 승인하면 그때 기준 파일/체크섬/기록을 함께 갱신한다.

자동 검사는 원본 변경과 좌표·여백 오류를 잡는다. 그림체나 손잡이가
완벽히 같은지는 이미지의 실제 내용을 보고 판단해야 한다.
