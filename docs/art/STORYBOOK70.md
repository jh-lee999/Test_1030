# v70 · 버터와 어울리는 동화풍 환경

요청: 맵과 소스를 트릭컬 분위기에 맞춰 예쁘게 정리한다.
장르·전투·성장·충돌·난이도·저장을 바꾸는 작업이 아니다.
현재 화면은 구현 후보이며, 사용자가 새 캐릭터 외형을 승인한 것으로 간주하지 않는다.
버터의 기준은 계속 [BUTTER_CANON.md](BUTTER_CANON.md)와 원작 전신 아틀라스다.

## 아트의 출처를 구분한다

- 원작 재사용: 버터/몬스터 전신, 숲/밤 배경 일러스트, 베개·날씨 카드 아이콘,
  기존 짱돌 및 출처가 있는 효과 아틀라스. 원본 파일/색/해시를 바꾸지 않았다.
- 팬 제작: `survivor70-art.js`의 상자·샘·균열·제단·주머니·꽃덤불·바위·버섯,
  새총/별사탕 등 벡터 아이콘. 원작에서 새로 추출한 소품이라고 표시하지 않는다.
- 코드 지형: `survivor70-scenery.js`의 잔디/꽃/길/디딤돌/울타리.
- 글꼴: 원본 Jua Regular 로컬 파일, Jua Project Authors, SIL OFL1.1.
  라이선스와 해시는 [소스 기록](../../assets/storybook70/CREDITS.md)에 포함한다.
  원작 그림에 글꼴의 라이선스가 적용된다는 뜻은 아니다.

게임 실행 중 외부 뷰어/CDN/폰트 서버에 요청하지 않는다. 기존 원작 권리·팬 게임 고지는
유지한다. 공개 접근과 비상업 목적만으로 원작 재배포 허가가 확인된 것은 아니다.

## 색과 형태

| 영역 | 적용 방향 |
| --- | --- |
| 숲 | 연두 잔디, 크림 디딤돌, 작은 흰 꽃/분홍 꽃, 나무·식물 소품 |
| 밤 | 청록·회보라 바닥과 길, 같은 소품의 차분한 식물 색, 밝은 캐릭터 대비 |
| 화덕 | 따뜻한 살구 바닥, 꿀색 디딤돌, 분홍 버섯·별사탕 색 |
| UI | 크림 종이, 꿀색 버튼, 라벤더 융합, 따뜻한 갈색 글씨/외곽선 |
| 원작 그림 | 색 필터·재생성·부위 분리·비균일 확대 없음 |

새 벡터 그림의 셀은128×136, 바닥 그림자는117 부근이다. 둥근 모서리와 부드러운
갈색 선을 쓰고 반짝임은 작은 별/꽃으로 제한한다. 사용자에게 보여줄 정보를
의미 없는 장식으로 바꾸지 않는다. 빈 슬롯/키보드 키/방향 화살표는 기능 기호다.
베개와 날씨 아이콘은 원본 PNG를 그대로 사용하고, 실패 시 팬 벡터 대체와 글자가 남는다.

## 실제 판정과 그림의 관계

v69 engine/world/content/profile와96판 balance 자료는 변경하지 않는다.
이전 루트는 SHA256 `e10cc864a4ed0dd09fd57ee2b22d7320e0df7529609bc470757d7eefbb367632`
그대로 `survivor69.html`에 남긴다. 새 화면도 동일한 저장 봉투를 사용하므로 이어하기와
영구 성장을 버리거나 마이그레이션하지 않는다.

- 길은 실제 `pathTo` 결과의 경로를 따른다. 막힌 땅으로 새 길을 그리지 않는다.
- 엄폐물 바닥은 실제 충돌 AABB다. 꽃밭/바위/버섯 몸체는 발 기준으로 캐릭터와 앞뒤 정렬.
- 균열125, 위험 구역68, 기술 지대의 각 반경은 엔진 값 그대로 그린다.
- 위험 예고/폭발은 분홍·붉은 선과 밝은 테두리로 구분한다. 우호 기술과 색/형태를 다르게 한다.
- 소품의 체크/진행 표시는 실제 ready/active/done을 읽는다. 그림이 보상을 지급하지 않는다.
- 버터의 원작 프레임·80 배율·공통 발·-22.4 Y 보정·좌우 반전·발사 시점은 그대로다.
- 모션 감소에서는 소품/효과의 추가 흔들림을 멈춘다. 팝업에서는 모든 효과가 같은 게임 시각을 읽는다.

지형은256px 청크로 그려 캐시한다. 렌더 전용 해시는 게임 RNG와 무관하며 상태를 쓰지 않는다.
LRU48청크, 최대12MiB는 **지형 캐시만의** 상한이다. 원작 아틀라스 등 전체 메모리의 주장은 아니다.
레이아웃 캐시는4개까지 유지한다. 렌더러는 상태를 변경하지 않는다.

## UI와 작은 화면

원작 숲/밤 원화는 시작 화면에 완전한 그림으로 재사용한다. 전투 바닥은 실제로 이동하는
월드 지형이며, 고정된 배경 집 그림을 움직이는 바닥처럼 겹치지 않는다.
새 그림 아이콘은 선택/클릭 대상을 교체하지 않고 내용만 장식한다.
한글 제목/버튼은 둥근 Jua, 설명은 읽기 쉬운 시스템 글꼴이다.

짧은 가로 화면은 시간 표시를 헤더 중앙, 체력을 왼쪽, 보스를 오른쪽에 배치한다.
거대 새총 모션이 나오는 중앙을 종이 패널로 덮지 않도록 한다. 큰 모션 자체의 원본
크기를 프레임마다 바꾸거나 잘라서 해결하지 않는다. 모바일 성장 선택과 상호작용은44px 이상.
선택 화면 글자 대비 검사 표본은4.55~5.59:1이었다. 포커스 테두리와 키보드 조작도 유지한다.
