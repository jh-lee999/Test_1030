# v72 · 강해진 권총, 화면 안 왕짱돌과 그림책 맵

사용자 요청은 권총이 새총보다 확실히 강할 것, 왕짱돌이 아래로 떨어지는 대신
현재 보고 있는 화면에서 튕기다가 일정 시간 뒤 사라질 것, 맵 그림을 개선할 것이다.
이전 루트는 해시까지 동일한 `survivor71.html`로 보존한다. 월드/엘리트/성장/융합은
v71 그대로이며 버터의 원작 전신 그림과 모션은 바꾸지 않는다.

## 옐로카드 권총

실제 발사와 설명이 공유하는 `primaryStats`에서 같은 랭크 새총의 피해를1.5배로
반올림한다. 랭크1/2/3은 각각14/18/23 →21/27/35. 간격은 새총0.62초 대비 권총0.34초.
탄속860, 추가 관통1, 기존 Lv2 귀환/벽 도탄과 Lv3 파쇄 및 융합을 계승한다.
이론적 평타 발사량만 비교하면 약2.7배이며 이동·타겟·엄폐/방패·시전 방해에 따라
실전 피해는 달라진다. 이미 예약한 탄환은 예약 당시 무기 종류를 유지한다.
원작 `OW1_Attack2_1` 전신·이동 사격 합성과 발사 이벤트는 그대로 사용한다.

## 왕짱돌: 월드가 아닌 지금 보이는 화면

- 원작 고학년의 실제 발사 시점·위치는 유지한다. 높은 새총 발사점에서 지면의 적을
  조준하던 하향 편향은 없애고, 방향은 버터의 전투 발 위치와 적의 위치로 계산한다.
  종/횡 성분을 모두 가지도록22.5..67.5도 안으로 제한한다. 중력은 없다.
- 속도640, 충돌 반지름36, 관통 피해90, 같은 적 재피해 간격0.45초.
  발사 후 **실제 전투 시간8초** 동안 존재하고 마지막0.5초에 사라진다.
- 현재 게임 캔버스의 네 변에서 반사한다. 일반 탄환과 달리 지형·월드 끝에
  반사되지 않는다. 벽 뒤로 지나가더라도 몹을 관통 타격한다.
- 렌더러와 물리가 같은 `cameraFor`를 사용한다. 캔버스의 CSS 논리 크기를 받고
  DPR은 표시 해상도에만 쓴다. 짱돌 그림 전체와 회전/링 여백을 안쪽으로 확보한다.
- 카메라가 따라 움직이면 짱돌도 화면 내 위치를 유지하며 이동한다. 화면 회전/
  리사이즈는 화면 내 상대 위치를 새 영역에 투영한다. 리사이즈/큰 순간이동으로
  생긴 가짜 가로지르기 피해는 없다. 반사 후 남은 이동 거리와 모서리 양축 반사를
  계산하며 실제 구간별로 충돌을 검사한다.
- 일시정지/성장창/재접속에서는 수명·반사·시전 시계가 멈춘다. 일시정지 중 화면
  크기가 바뀌어도 표시 투영만 수행하고 게임 상태는 쓰지 않는다.
- 옐로카드의 고학년2회는 여전히18초 쿨다운 한 번에1.1초 시전 두 번이다.
  각각의 원작 발사 이벤트에서 별도 짱돌이 나온다. 시전 동안만 무적이며
  두 번째 예약은 저장/재접속 후 남은 한 번만 실행한다.

## 맵 그림

기존 원작 숲 배경을 스타일 참조로 삼아 숲/밤/화덕 풀밭과 나무·수풀·바위·버섯·
그루터기·꽃·통나무·고사리, 왕짱돌을 새로 만들었다. **AI 생성 팬 그림**이며
트릭컬 원작 추출 에셋이나 공식 사용 허가가 아니다.
[PNG 원본·WebP 변환·출처·해시](../assets/storybook72/CREDITS.md)를 보존한다.
버터/몬스터/원작 이펙트/아이콘의 원본은 수정하지 않는다.

바닥은1024월드 단위로 교대 반전해 가장자리 연결을 맞춘다. 그림 자체가 완벽한
심리스라는 주장은 아니다. 얇은 흙길과 불규칙한 디딤돌은 실제 `pathTo` 경로를
따른다. 큰 소품은 실제 엄폐물에만 두고 작은 꽃/고사리는 빈 지면에 시드로 배치한다.
원본 셀의 측정된 발 기준으로 지면에 붙이고 깊이순으로 그린다. 버터를 가리는
수관만 반투명해진다. 관심 지점/위험 반경과 충돌 형상은 바꾸지 않는다.
그리기와 길/타일 캐시는 전투 RNG나 게임 상태를 변경하지 않는다.

지형 캐시는256×256 RGBA48장, 최대12MiB. 레이아웃4개. 이는 전체 브라우저/
원작 전신 시트/GPU 메모리 측정값이 아니다. 이미지가 늦게 도착하면 캐시를 갱신하며,
에셋 실패 시에도 단색 바닥/기존 대체 그림으로 시작과 전투가 유지된다.

## 이어하기

새 키 `butter.survivor72.v1`이 없을 때 유효한 v71 프로필과 진행 중인 판을 가져온다.
runId/HP/RNG/자원/쿨다운/선택 예약을 유지하고 같은 후보ID의 설명만 갱신한다.
기존 짱돌은 남은 수명을8초 이하로 제한할 뿐 리필하지 않는다. 구키에 쓰거나
보상을 지급하지 않는다. 가져오기 후 두 보관본은 독립 진행이며 구버전 재플레이의
재화를 새 키로 계속 합치지 않는다. 손상되거나 사용할 수 없는 저장소는 경고한다.

## 검증과 한계

- 세 랭크의 실제 제어된 투사체 적중 피해를 비교했다. 권총은 각각의 새총보다
  강하다. 카메라 이동·320세로/568가로/844/1366/8K 화면에서 경계/속도/모서리
  반사, 지형 무시, 관통,8초 소멸, 메뉴/재접속과2회 예약을 단위 검사한다.
- 브라우저에서 실제 시작/이동/선택/고학년2회와 재접속,320/390/568/844 터치,
  카메라 이동·화면 회전·일시정지 중 리사이즈의 전체 짱돌 경계를 확인했다.
  상자 위치와240명 스트레스는 별도 fixture이며 정상 완주와 섞지 않는다.
  이미지 요청 실패로도 조작 가능하고 콘솔 오류는 없었다.
- 새 그림10파일의 해시/크기, 소품8셀과 최소27px 투명 여백/발 기준을 검사한다.
  기존 원작1044포즈/26파일 및 승인 마스터 해시는 그대로 검사한다.
- 별도 실제 DOM/키보드만 사용한 자동 정책 런: balance-0,233.06초 탈출/Lv24,
  봉인2/융합2, 권총569발, 왕짱돌19회 발사/200회 반사,33조각. HP/위치/아이템/
  시계 주입은 없었다. 결과 기록과 연구 구매 후 재접속 유지도 확인했다.
- [소스 해시 고정48회 정책 진단](survivor72-balance.json): 숲4시드·밤/화덕2시드씩,
  가만히/이동만/목표 수행×신규/최대 연구. 목표 수행15/16탈출, 가만히0/16,
  이동만0/16(상호작용을 안 해서 승리 불가). 숲 신규 목표 수행 피해 중앙값136,
  시간 중앙값226초. 진단 뷰포트1120×630과 실제 완주1366×702는 다르다.

자동 정책·이 표본·기술 검사는 사람의 승률/재미나 최적 난이도/새 그림의 미적
승인을 뜻하지 않는다. 화면 비율이 짱돌의 범위/반사 빈도에 영향을 주는 것은
요청한 규칙의 결과이며, 실제 기기와 사람의 플레이 피드백을 더 확인해야 한다.
