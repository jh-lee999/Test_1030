# v63 · 손패 전체 버리기

요청: 한 번에 버릴 수 있는 카드가5장에 묶이지 않고 손패 전부여야 함.

- `toggleCard`의5장 제한을 제거. 실제 손패에 존재하는 카드는 전부 선택 가능.
  현재 손패는8장이며 개별 클릭/숫자1..8 모두 동작한다.
- `selectAllCards`는 일부 선택→전체 선택, 전체 선택→해제로 전환.
  직접 선택만 바꾸며 RNG/카드 더미/횟수/유물 충전/공격을 실행하지 않는다.
- 별도 `버리기`/R 입력에만 실제 교체.1..현재 손패 수만큼 고를 수 있고
  **8장을 골라도 버리기1회만** 차감. 기존처럼 손패8장까지 보충한다.
- 빈 선택, 손패보다 많은 선택, 중복 ID, 존재하지 않는 ID, 횟수0, 잠긴 단계는
  비용/더미/RNG를 전혀 바꾸지 않는다. 현재 선택 카드 수에 관계없이 동일 검증.
- 공격·일시정지·상점 등 pick 외 단계에서 전체 선택과 버리기는 불가능.
  횟수0일 때 선택은 가능하지만 실제 버리기는 안 된다. 메뉴로 충전되지 않는다.
- 카드 더미가 소진되면 기존 버린 더미를 다시 섞는다. 이미 버린 카드가 다시
  나올 수 있지만 실제 덱의 고유 ID가 중복되거나 유실되지 않는다.
- 족보 득점은 여전히 최대5장. 유물 서순/자동 최대 피해/구성 카드 확인/공격 횟수,
  턴별 버리기 충전과 횟수 유물 규칙은 변경하지 않았다.

UI는 전체 선택/해제 토글과 기존 선택 해제, 선택N장 버리기를 함께 표시한다.
전체 선택만 누르거나 그 버튼에서 Enter/Space를 누르면 발사하지 않는다.
도움말도8장 버리기와5장 득점을 구분한다. 정상6전투 진단 정책의 최대5장 선택
휴리스틱은 그대로이며, 게임의 허용 장수와는 별개다.

단위6개: 개별6~8장/전체8장1회비용, 선택만 바꾸는 토글,1..8장 부분집합,
잘못된 상태 원자성,20장 덱 반복 전체 교체/유물 보너스4회, 득점5장/턴 충전 분리.
새 브라우저는 정상 시드61에서8장 각각 선택→전체해제/선택/Enter→8장 교체를
실제 버튼으로 수행. 버리기는3→2, 공격은4로 유지, 카드8장 보충/선택해제 확인.
그 뒤 실제 공격·반격을 마치면 버리기3회가 다시 차는 것도 확인한다.
모바일 터치와320·390·760·844폭, 족보 확인 독립, 공격 중 잠금도 검사한다.
기존 정상 자원6전투·v59~62·아카이브·전체 단위·아트 검사를 유지한다.
원작 에셋이나 전투 밸런스는 바꾸지 않았다. 검사 통과를 재미의 검증으로 보지는 않는다.
