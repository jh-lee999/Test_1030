# v60 · 현재 패가 완성한 족보

요청: 현재 패로 무엇을 달성했는지 바로 볼 수 있어야 함.
기존 접힌 족보 사전은 보존하고, 손패 바로 아래에 항상 보이는 완성 족보 패널을
추가했다. 게임 엔진·족보 판정·유물 서순·자원·전투·원작 아트는 변경하지 않았다.

## 표시와 조작

- `evaluateHands()`가 반환하는 실제 득점 가능한 족보를 전부 표시. 이름, Lv,
  구성 카드 수, 현재 유물/훈련/적 방어를 반영한 예상 피해.
- 현재 실제 최대 피해 족보를 맨 앞의 금색 `자동 · 최강`으로 표시. 나머지는
  피해 순, 완성했지만 보스가 금지한 족보는 `완성 · 보스 봉인`으로 뒤에 표시.
- 족보를 누르면 해당 족보의 카드들에 청록 테두리. 구성 카드의 무늬·숫자 목록과
  칩×배수/임시 방어도 함께 표시. 다른 족보 확인 중에는 돌아가기 버튼 제공.
- 금색 자동 득점과 붉은 버리기 선택은 그대로다. 카드에 청록 확인 표시와 금색
  득점이 겹칠 수 있으며 상태 라벨로 구분한다. 확인 중인 약한 족보를 공격하도록
  바꾸거나, 클릭만으로 버리기/공격/금전/RNG를 소모하지 않는다.
- 손패가 실제로 바뀌거나 턴·방이 바뀌면 확인 표시 초기화. 같은 손패의 버리기
  체크만 바꾸면 확인은 유지. 유물 순서 변경 시 피해와 자동 최강은 재계산하면서
  여전히 존재하는 확인 대상은 유지한다.
- 공격 확정 후에는 `pending.result` 한 개만 표시하고 적중까지 피해를 고정.
  보스가 그 족보를 다음 턴에 봉인한다고 방금 발사한 공격을 금지 상태로 바꾸지 않음.
  일시정지/확정 중에는 확인 버튼을 잠그고 다음 패에서 다시 활성화한다.

목록은 엔진의 정확한 **득점 부분집합**을 표시한다. 예컨대 로열5장은 로열로
분류되며, 그 똑같은5장을 더 낮은 플러시/스트레이트 공격으로 새로 발명하지 않는다.
8장 안에 다른 부분집합이 그 족보를 만들면 해당 후보도 표시된다.
영구 업적이나 수집 도감이 아니라 현재 전투의 손패 상태다.

## 검증

- 단위6개: 엔진 결과와 목록 일치/최강 정렬/읽기 전용, 약한 족보 확인과 실제
  자동 발사의 독립, 봉인된 완성 족보와 합법 패 없음, 확정/일시정지 스냅샷,
  로열·포카드·A2345·불법 A랩, 서순 변경 시 실제 최강 재선정.
- 새 브라우저는 정상 시드58 첫 손패의 투페어144/원페어84를 실제 버튼으로 확인.
  원페어를 확인해도 득점 카드는4장 그대로이며, 실제 공격은 투페어로 나간다.
  확인/Enter/돌아가기 전후 게임 상태(time 제외)가 같고 버리기 체크도 독립이다.
- 이후 풀하우스/봉인/서순 변경은 별도의 명시적 상태 주입 UI 검사.
  320·390·760·844폭, 모바일 터치, 확정 중 표시 고정, 새 패 초기화도 검증.
- 별도 poker58 정상 자원6전투, order59, 이전 주사위·횡스크롤·핀볼·원작 모션,
  전체 단위/소스 아트 검사 유지. UI 검사가 사람의 재미 검증을 뜻하지 않는다.

현재 진입 주소 둘의 캐시는60. `poker58.html`은 최신 코드 별도 진입 주소이고,
v57 이하 보존본과 소스 에셋은 그대로다.
