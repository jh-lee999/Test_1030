# v58 · 덱을 다듬어 족보를 만드는 카드 런

사용자 요청: 주사위에 몇 개의 족보 이름만 붙이는 대신, 발라트로처럼 덱 압축과
스트레이트·풀하우스·포카드·로열 등을 포함한 실제 빌드 구조. 발라트로의
유한 손패/버리기, 족보별 성장, 덱 편집, 칩×배수 유물, 이자에서 개념을 참고했으며
발라트로 에셋/코드/전체 콘텐츠를 복제한 것은 아니다.

## 한 판의 구조

52장(4무늬×2..A)으로 시작 → 빌드 유물 선택 → 전투 → 보상 골드 → 상점에서
덱/족보/유물/회복 중 투자 → 일반/정예 경로 → 여섯 번째 이불령 보스.
시작 유물: 같은 숫자 재발동 리본 / 플러시×1.8 / 스트레이트×2.
모든 편집·족보 레벨·유물·충전은 이번 런에서만 유지. 영구 성장 없음.

- 손패 8장. 각 카드의 고유 ID로 원본과 복제본을 따로 추적한다.
- 전투 전체에서 공격 4회, 버리기 3회. 공격 후 버리기가 리필되지 않는다.
- 클릭/숫자1..8로 **버릴 카드** 최대5장 선택, R/버리기로 교체. 카드 선택만으로
  자원·RNG는 변하지 않는다. 공격은 Space/공격 버튼, 자동 발사하지 않는다.
- 공격 시 모든 1..5장 부분집합을 검색, 유물/레벨/방패/빈틈/처형을 반영한 실제
  최대 피해 합법 족보를 자동 사용. 같은 피해는 방어가 큰 쪽. 득점하지 않은
  카드는 손에 남고 득점 카드만 버린 뒤8장까지 보충한다.
- 뽑을 더미가 비면 버린 카드를 섞는다. 손에 있는 카드가 중복되어 나오지 않는다.
- 족보의 빈 득점 칸(5−득점 카드 수)당 방어2, 이후 보호막이 반격을 흡수.
  마지막 공격에도 적이 살아 있으면 실패. 반복 공격으로 무제한 시간 끌기 불가.
- 원페어로 방패 파괴. 적 행동은3턴 순환, 빈틈×1.35. 보스는 직전 족보 봉인,
  절반 HP부터 반격+3/항상 빈틈. 금지 상태에서는 해당 족보 자동 제외.
  합법 족보도 없고 버리기도 없으면 반격을 받는 빈손 넘기기로 진행 가능.

## 족보와 성장

| 족보 | 득점 카드 | 기본 칩×배수 | 강화당 증가 |
| --- | --- | --- | --- |
| 하이 카드 | 1장 | 5×1 | +10칩 / +1배수 |
| 원페어 | 같은 숫자2장 | 10×2 | +15 / +1 |
| 투페어 | 짝2개,4장 | 20×2 | +20 / +1 |
| 트리플 | 같은 숫자3장 | 30×3 | +20 / +2 |
| 스트레이트 | 연속5장 | 30×4 | +30 / +3 |
| 플러시 | 같은 무늬5장 | 35×4 | +15 / +2 |
| 풀하우스 | 3+2 | 40×4 | +25 / +2 |
| 포카드 | 같은 숫자4장 | 60×7 | +30 / +3 |
| 스트레이트 플러시 | 같은 무늬의 연속5장 | 100×8 | +40 / +4 |
| 로열 스트레이트 플러시 | 같은 무늬10JQKA | 120×10 | +40 / +4 |
| 파이브 카드 | 같은 숫자5장 | 120×12 | +35 / +3 |
| 플러시 하우스 | 같은 무늬의3+2 | 140×14 | +40 / +4 |
| 플러시 파이브 | 같은 숫자·무늬5장 | 160×16 | +50 / +4 |

각 득점 카드 칩:2..10은 숫자, J/Q/K는10, A는11.
A2345와10JQKA는 허용, QKA23은 불가. 로열은 무늬까지 같아야 한다.
복제 카드도 고유 ID가 다르므로 특수 족보를 실제로 만들 수 있다.
족보 강화는 Lv1→Lv9까지 누적. 높은 명목 족보보다 훈련한 작은 족보의
실제 피해가 높으면 작은 족보가 자동 선택될 수 있다.

한 장 모자란 플러시/포카드/스트레이트 힌트는 남은 더미의 후보 수를 표시한다.
누르면 버릴 카드만 선택한다. 숨겨진 카드 순서를 보거나 보장된 확률이라고
표시하지 않는다. 덱 보기에서 실제 무늬/숫자별 장수를 볼 수 있다.

## 돈과 덱 편집

시작12 G. 승리 시 기본8 G(정예14) + 남은 공격당2 + 승리 전 보유 돈의
5 G당 이자1(최대5). 지급은 한 번. 회복 자동 지급 없음.

| 서비스 | 가격/제한 | 실제 변화 |
| --- | --- | --- |
| 제거 | 첫4 G, 두 번째6 G / 상점2회 | 선택한1장 런 덱에서 제거, 최소20장 |
| 복제 | 6 G / 상점1회 | 선택한 숫자·무늬의 새 고유 ID 카드1장 추가 |
| 무늬/숫자 변경 | 3 G / 합쳐서 상점2회 | 선택한1장의 속성을 원하는 값으로 변경 |
| 족보 강화 | 5 G / 상점2회 | 그 족보 레벨+1, 최대8회 강화 |
| 회복 | 4 G / 상점1회 | HP+16, 최대치 제한 |
| 유물 | 8 G | 4칸, 꽉 차면 교체 대상 명시 후 결제 |
| 카드 팩 | 4 G / 상점1회 | 고정된3장 중1장 추가 |

구매 검증 전 돈/덱을 변경하지 않는다. 취소/둘러보기로 재고·RNG·가격을
리셋하지 않는다. 유물 교체 시 해당 유물 충전만 정리한다.
정예는 HP×1.45/반격+3, 기본 보상14 G. 최종 보스 HP2300.

## 유물과 원작 자료

기존 원작 참고8종의 PNG와 출처는 `assets/trickcal-artifacts53/` 그대로다.
해당 자료는2025년 스냅샷이고, 현재 원작 밸런스/에셋 사용 허가를 검증했다는
뜻이 아니다. `trickcal-artifacts.js`의 원작 요약은 보존하고 `poker-engine.js`의
효과는 **카드 규칙용 새 각색**으로 구분한다. 기존 팬 유물6종과 새 팬 스타터2종,
총16종. 발라트로의 조커 에셋이나 이름을 가져오지 않았다.

리본은 같은 숫자 득점 카드를 딱1회 추가 발동. 별사탕은A/J/Q/K칩+8,
꼭 쥔 행운은하트당배수+.5, 번개는3번발동당칩+18/충전유지. 방울은남은버리기당칩+10,
빈주머니는버리기0에서배수+3, 고무줄은최종×1.5. 옐로카드는트리플이상강화/분노,
림의낫·흡혈·메이스는하이/페어/투페어에적용. 나머지보호막·위기회복·상처는
기존의 실제 HP 손실/사망 되돌림 금지 규칙 유지. 발동 순서는 점수창에 표시.

버터·몬스터·배경·탄환 원본과 스케일/앵커는 바꾸지 않았다.
공유 렌더러의 변경은 옵션형 중앙 대기 문구뿐이며 이전 기본값 유지.
v57 `index.html`은 SHA256
`16a8e425bba9ef28f17078fe3447dc6b5d0de801eef3000e68aa8f7fc387d066`로
`dice57.html`에 원문 보존. v54/새총/횡스크롤/탑다운 보존.

  카드와 보이지 않는 카드의 **분포**를 샘플링할 뿐 다음 카드 순서를 보지 않는다.
  카드/돈/HP/성장을 주입하지 않고 실제 모션 시간을 기다린다. 이후 로열과
  카드변환 등의 명시적 상태 주입 검사는 이 실제 자원 런과 별개다.
  `poker58-0`의 실제 버튼 런: 공격11회/버리기7회/카드제거8장/족보강화3회,
 6전투 완료. 개발자가 수동으로 플레이했다는 주장은 아니다.
- `tools/playtest-poker58.mjs`의12개시드 샘플 정책은10승2패였다. 이는 작은
  진단표본이며 전체 난이도·사람의 재미·최적 전략의 증거가 아니다. 스타터
  강화와 덱 편집이 동작하는지 점검하기 위한 자동화다.
  같은12시드에서 버리기/구매 없이 공격과 이동만 반복한 비교 정책은0승,
  1~5전투에서 실패했다. 정책 간 행동의 결과 차이 확인이지, 재미의 증거는 아니다.
- UI/게임 크기 캡처, 모바일 터치/320·390·760·844폭, 도움말/일시정지,
  기존 v57/v54/핀볼/횡스크롤/원작 재생 및 소스 아트 검사도 점검한다.
