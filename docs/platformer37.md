## 구성

- `platformer-engine.js`: DOM 없는 120Hz 고정 스텝 물리/전투/시드 배치/진행.
- `platformer.js`: 이미지 준비, 키보드/멀티터치, 프레임 사이의 짧은 입력 큐,
  포커스 이탈 정지, 보상/실패/탈출 UI. `?test=1`에만 테스트 fixture API 제공.
- `platformer-renderer.js`: v36 전신 원작 프레임과 동일한 발사점 반전,
  몬스터 3종, 원작 숲 2종, 게임용 발판/이펙트. 전체 포즈만 렌더.
- `topdown36.html`: 이전 버터/코미 방 탐험 구현 보관. `app.js` 변경 없음.
- `assets/trickcal-stage37/`: 408 몬스터 포즈, 2 배경, 원본 URL/해시/권리 기록.

왕새총 애니메이션은 원작 Ultimate를 재시간화한다. 화면의 계속 구르는 짱돌은
게임 코드의 도형이며 원작 바위 추출물이 아니다. 이불령의 보스 역할/탄막도
이 프로토타입의 전투 설계다. 플랫폼 발판은 원작 배경에서 잘라낸 타일이 아니다.
