# v42 캠페인

기존 7구간 한 지역을 3막·21구간으로 확장했다. 스컬에서 참고한 설계는
지역 돌파와 보스라는 목표, 원거리/근접 적 조합에 따른 대응, 보스 보상으로
빌드를 강화하는 박자, 아이템과 상점 자금 중 선택하는 경제다. 기존 각인·
중복 아이템·상점·계약과 연결한다. 이번에 스컬 플레이 영상을 분석했다거나
원작 수치·패턴을 그대로 재현한 것은 아니다.

| 지역 | 전투 구성 | 지역 보스 |
| --- | --- | --- |
| 뒤틀린 숲 | 숲/수관 발판, 근접 적 비중과 추격 속도 증가 | 열혈팬 기반 문지기: 점프로 피하는 양방향 충격파 |
| 잊힌 회랑 | 석조 발판/아치, 궁수 비중 증가, 바닥 마력 경고 | 극성팬 기반 저격수: 조준 5연사, 격노 시 낙하탄 추가 |
| 셰이디의 아공간 | 어두운 틈새 장식, 강화 적 3연사, 짧은 위험 지대 주기 | 이불령: 방사형 탄막과 조준탄, 격노 시 탄막 밀도 증가 |

각 막은 기존과 같이 전투·정예·보물·휴식·상점 갈래를 갖는다. 6/13 깊이의
보스 출구에서는 다음 막으로 이동하며, 20 깊이에서만 승리한다. 상점은 매 막
첫 전투 출구와 1/3/5번 깊이에 배치한다. 빌드와 도장·할인권은 막 간 유지.
지도는 현재 막의 7개 열과 전체 3막 진행 띠로 구성해 휴대폰에서도 읽을 수 있다.

보스 체력이 절반 이하면 공격 주기와 패턴이 강화된다. 이미 시작한 공격의
예고 시간은 중간에 단축하지 않는다. 보스 보상은 영웅 등급 3택1이며 재추첨도
영웅 등급을 보장한다. 일반 전투에서는 아이템 대신 14+막번호×8 G를 선택할 수
있고, 지도에 ‘자금 보상 ↑’로 표시된 경로는 28+막번호×8 G를 준다(막번호 0~2).
보물/보스에는 자금 대체 선택이 없다. 중복 수령 불가.

위험 지대는 경고 .9초 후 활성 .4초. 회랑 주기 4.5초, 아공간 주기 3.6초.
지면 근처 플레이어만 피해를 받으며 점프·대시·스킬 무적으로 회피 가능하다.
메뉴에서는 정지하고 방을 클리어하면 비활성화한다. 낙하 복구와 발판 물리는
변경하지 않았다. 1,000개 시드 전체 방과 실제 점프 증거 경로를 다시 검증한다.

새 원작 몬스터나 배경을 다운로드한 변경은 아니다. 기존 원작 배경 2장과
몬스터 3종을 재사용하고, 지역 장식/위험 지대/보스 행동을 구현했다. 보스 명칭은
팬게임 역할명이다. 스컬 교대·정수 슬롯·영구 성장·저장 기능은 이번 범위에 없다.
21구간을 강제로 길게 플레이하는 피로도와 실제 빌드별 난도는 추가 플레이
피드백으로 조정할 부분이다. 기술 검증은 미적 완성도나 밸런스 승인을 뜻하지 않는다.

검증: campaign42 단위 검사(3막 이동/희귀도/보스 실탄/경고 판정/일회 보상),
기존 성장·연쇄·경제 검사, 21구간 전체 브라우저 진행, 모바일 지도와 상점,
원작 에셋/미리보기 회귀 검사.
