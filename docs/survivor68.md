# v68 · 버터의 말썽 대탈출

사용자 요청: 발라트로는 접고, 뱀서 + 포켓봉크 쪽으로 돌아간다.
복잡한 손패·족보·버리기·칩 계산·턴별 반격·유물 정렬은 새 게임에 가져오지 않았다.
기존 루트는 `cards67.html`로 바이트 그대로 보관하며 카드 엔진과 저장은 변경하지 않는다.

## 참고 자료와 한계

제공된 중복 주소는 <https://pokebonk.com/?lang=ko>로 정리했다.
직접 접속은 환경의 CONNECT 프록시 정책에서 403으로 거부되어 플레이하지 못했다.
접근 제한을 우회하지 않았다. 아래 공개 README의 설명만 읽었다.

- <https://github.com/CharcherGit/pokebonk-app> — 공식 사이트를 띄우는 팬 데스크톱 래퍼.
- <https://github.com/v-reza/pokebonk-re> — 기술 레벨/업그레이드, 진화, 아이템, 지역별 생존을 설명하는 비공식 문서.

두 번째 저장소의 실행 파일·게임 코드·리소스·잠금 해제 로직은 가져오거나 실행하지 않았다.
이 구현은 공개 설명에서 전투/성장 방향만 참고한 **독립 각색**이다. 포켓봉크와
같은 기술·수치·진화 규칙이라고 주장하지 않으며 포켓몬 에셋도 사용하지 않았다.
현재 생물/캐릭터 교체형 진화가 아니라, 기존 트릭컬 에셋에 맞춘 **기술 각성**이다.

## 한 판의 흐름

1. WASD/방향키/터치 스틱으로 이동. 가까운 적에게 새총을 자동 발사한다.
2. 적이 떨어뜨린 경험치를 주워 레벨업하고, 멈춘 화면에서 세 선택지 중 하나를 고른다.
   경험치가 여러 레벨 분량이면 모든 성장 선택이 차례로 열린다.
3. 최대 4개 기술을 습득하고 각 Lv5까지 강화한다. 일반 능력치 강화도 같은 판에서 누적된다.
4. 정예(45/110/175초), 중간 수호자(90초)를 처치하면 회복과 각성 핵을 얻는다.
   Lv5 기술은 다음 성장 선택에서 핵 하나를 써서 한 번만 각성할 수 있다.
5. 240초에 최종 이불령 등장. 시간을 버티는 것만으로 승리하지 않고 실제로 처치해야 한다.

| 기술 | 성장/각성이 바꾸는 실제 공격 |
| --- | --- |
| 버터의 새총 | 탄 수 증가, 관통, 각성 시 3갈래 관통 |
| 말썽 유도탄 | 레벨/저학년 참고서마다 튕김 증가, A→B→A 재타격, 각성 시 더 긴 사거리 |
| 베개 호위 | 근접 적 피해·밀치기, 베개 수/반경 증가, 각성 시 4개 |
| 날씨는 맑음 | 가까운 적 번개·짧은 기절, 표적 수 증가, 각성 시 6개 |
| 별사탕 폭탄 | 지연 범위 폭발, 각성 시 더 넓은 폭발 + 주변 연쇄 폭발 |

능력치는 공격력(+15%), 공속(+12%), 이속(+8%), 체력(+20 및 회복),
경험치 자석(+35), 저학년(유도탄 튕김+1), 고학년(왕새총 피해·쿨다운)이다.
E/Space 왕새총은 원작 고학년 모션의 발사 시점에 큰 관통 짱돌을 내보낸다.
짱돌은 6초간 벽에서 튕기지만 무적은 **시전 1.1초 동안만**이다.
현재 원작 저학년 동작을 별도 액티브로 재현하는 규칙은 아니며, 유도탄은 자동 기술이다.

## 조작·화면·저장

- 이동에 집중하는 단일 전투 화면. 위쪽 체력/경험치/시간, 아래쪽 네 기술과 왕새총.
- 돌진/사격/범위 공격은 고정된 방향이나 지점을 미리 표시한다. 예고 후에만 공격한다.
- 화면 밖 수호자는 방향 표시로 안내한다. 보스가 어디 있는지 찾지 못해 끝없이 떠돌지 않게 한다.
- P/Esc 일시정지, B/I 기술·누적 스탯 보기, 도움말. 팝업은 시간·탄환·쿨다운을 모두 멈춘다.
- 터치 스틱과 왕새총 동시 입력, 키보드 선택 1/2/3, 포커스 가두기, 모션 감소 설정 대응.
- 별도 저장 키 `butter.survivor68.v1`. 10초/선택/일시정지/탭 이탈 체크포인트.
  이어하기는 안전하게 일시정지로 시작하며, 미선택 레벨업과 진행 중 탄환도 그대로 복구한다.
  손상/차단 저장은 경고와 함께 새 판 플레이가 가능하다. 영구 스탯 성장이나 온라인 저장은 없다.
- 새 판은 남은 탐사를 덮어쓰기 전에 확인한다. 승패 화면에는 시간/레벨/처치/빌드와 재도전.

## 에셋 보존

원작 Butter idle/walk/shoot/high 및 기존 같은 리그 walkShoot 합성 전신을 그대로 사용한다.
발사점·그림은 같은 크기80/발 기준/Y 보정/좌우 반전을 공유한다. 머리·팔다리 분해,
개별 프레임 자동 맞춤, 새 방향 그림 생성, 재채색은 없다. 위/아래 시점 원본은 추가되지 않았다.
몬스터 5종과 배경은 기존 `trickcal-stage37`, 발사 효과는 기존 효과 아틀라스,
베개는 기존 아이콘을 재사용한다. 원본 파일/해시/크레딧은 변경하지 않는다.
비공식 팬 게임이며 비영리라는 이유만으로 이용 허가가 생기는 것은 아니다.

## 검증 구분

`test/survivor68.test.js`: 결정적 시드/분리 RNG, 이동/정지, XP 초과분,
실제 누적/슬롯/각성 제한, 원작 발사 시점과 방향, 연속 튕김 재타격/유한 수명,
관통 중복 방지, 근접/기절/범위 공격, 무적/쿨다운, 고정 예고, 보스 출현/처치, 저장 검증.

`tools/check-survivor68-browser.mjs`: 실제 경과 시간과 DOM/키보드 입력의 32초 전투를
별도로 보고한다. XP/위치/체력 주입 없는 구간에서 이동·사격·처치·경험치 성장·이동 사격을 확인한다.
이후 큰 경험치·보스·저장 등의 개별 규칙은 **명시적 fixture**로 분리하며 전체 런으로 세지 않는다.
320/390/844 뷰포트 터치/동시 왕새총/성장 버튼, 모션 감소, 모든 그림 실패,
저장 차단/대기 선택 복구, 읽기 전용 렌더러를 검사한다. 캡처는 `/tmp/survivor68-*.png`.

초기 엔진 진단(동일 이동/선택 정책, 시드0~3): 정지는 17~22초에 4/4 사망,
이동·경험치 회수 정책은 240~328초에 3회 사망/1회 최종 처치였다.
이는 고정 자동 정책 표본일 뿐 사람의 난이도·재미·다양한 빌드의 균형을 입증하지 않는다.
새 루프는 구현/검증 대상인 초기 버전이며, 상업용 완성도를 달성했다고 평가하지 않는다.

실행: `npm start` 후 로컬 페이지. `npm test`, `npm run check:butter-canon`,
`npm run check:butter-original`, `npm run check:platformer-art`, `npm run check:sprites`.
브라우저 검사는 Playwright/Chromium 경로를 지정해 해당 `.mjs`를 실행한다.
기존 카드 브라우저 검사는 URL만 `cards67.html`로 바꾸어 보존본에 계속 실행한다.
