# 달빛 마을 RPG

모바일 화면에 맞춘 실시간 탑다운 액션 RPG입니다. 캐릭터를 직접 움직여 NPC에게 퀘스트를 받고, 마법으로 슬라임과 보스를 물리쳐 달빛 마을을 지키는 것이 목표입니다.

- 가상 조이스틱 및 키보드 이동
- 실시간 마법 전투와 적 AI
- NPC 대화, 퀘스트, 보스전
- 경험치, 레벨업, 체력, 회복 물약, 전리품
- 자동 저장과 오프라인 플레이

## 실행

별도의 의존성 설치는 필요하지 않습니다. 저장소 루트에서 다음 명령을 실행하세요.

```bash
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다. 같은 네트워크의 휴대폰에서 테스트하려면 개발 컴퓨터의 로컬 IP와 포트 `4173`을 사용하세요.

## 테스트

```bash
npm test
```

게임은 진행 상황을 브라우저의 `localStorage`에 자동 저장합니다. 서비스 워커와 웹 앱 매니페스트가 포함되어 있어 지원되는 모바일 브라우저에서는 홈 화면에 설치하고 오프라인으로 플레이할 수 있습니다.
