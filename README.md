# 별빛 생존자

모바일 우선의 클래식 생존 액션 게임입니다. 캐릭터 이동만 직접 조작하고 공격은 자동으로 발사됩니다. 몰려오는 적을 처치해 경험치 결정을 모으고, 레벨이 오를 때마다 세 가지 증강 중 하나를 선택해 3분 동안 빌드를 완성합니다.

## 주요 시스템

- 가상 조이스틱 또는 WASD/방향키 이동
- 가장 가까운 적을 자동 조준하는 마법 공격
- 가까운 적을 광역으로 베고 밀어내는 초승달 참격
- 시간이 지날수록 강해지는 다중 웨이브와 정예 적
- 경험치 결정과 레벨업
- 레벨별 필요 경험치 증가와 초과 경험치 이월
- 한 번에 여러 레벨이 오르면 횟수만큼 연속되는 증강 선택
- 매 레벨 세 가지 중 하나를 고르는 증강 시스템
- 별마탄 전용 관통·유도·초신성 증강
- 초승달 전용 흡혈·처형·근접 방어 증강
- 공전 칼날 획득 후 해금되는 과회전·쌍성 궤도 증강
- 공용 증강을 포함한 총 21종의 빌드 선택지
- 자주색·금색·청백색으로 통일한 다크 판타지 캐릭터 및 전투 아트
- Blender 메시 변형으로 렌더링한 캐릭터별 8프레임 애니메이션
- 양발 착지·교차·상승과 중간 자세가 분리된 플레이어 16프레임 워크 사이클

레벨 1에서 400 XP 정예 결정을 획득하면 100, 120, 140 XP가 차례로 소비되어 레벨 4가 되고, 남은 40 XP를 유지한 채 증강 선택이 세 번 연속 진행됩니다.
- 모바일 브라우저 및 홈 화면 설치 지원

## 실행

별도 의존성 설치는 필요하지 않습니다.

```bash
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 테스트

```bash
npm test
```

Blender가 설치된 환경에서는 `npm run render:animations`로 캐릭터 애니메이션 시트를 다시 렌더링할 수 있습니다.
